【教程】自动化风格探索器，请躺好，自动收图就完事了！

发表于2026-06-10|行业观察
|浏览量:

本文转载自 X 博主 @vibeshotclub（VibeShotClub） 的长文，原文链接，版权归原作者所有。

这篇教程在gpt-image2刚出来没几天就发到VSC论坛了，现在社区的小伙伴基本都已经跨进自动化跑图时代了，但最近还有推友来私信我咋自动化跑图。
那就再发一次吧。
论坛原贴：https://vibeshot.club/forum/0619ef70-36c8-46a0-949a-9b1f8b76fe8d

正文开始。

不要再用香蕉的提示词思路，来玩GPT-IMAGE2。

群里斗图斗了几天几夜，大家应该都有一个共识：GPT其实不需要特别复杂的提示词，就能出片。

但到底有哪些风格？太多了..

极简主义、包豪斯、赛博朋克、蒸汽朋克、电影感，这些词当然还能用，但它们已经被反复消耗。你写出来，别人也写出来，模型见得太多，最后生成的东西就容易滑向一种“熟悉的平均值”。

所以我做了一个 rare-style-explorer skill。

它是一个风格探索工具，里面整理了 600 +个更适合生图的稀有亚种风格标签（好消息！🥳现在在VSC网站上可以直观看到每种风格长什么样，全部整理好了！https://vibeshot.club/lexicon）

比如：

  • 液态铬金属 / liquid chrome
  • 邵氏武侠棚拍 / Shaw Brothers wuxia studio backlot
  • 八十年代 OVA 赛璐璐 / 1980s OVA anime cel
  • 意大利铅黄恐怖灯光 / Italian giallo horror lighting
  • PS1 低多边形恐怖 / PlayStation 1 low-poly horror
  • 复印朋克传单 / xerox punk flyer
  • 软胶 Sofubi 玩具 / sofubi vinyl toy
  • 昭和喫茶店 / Showa-era kissaten cafe
  • 铁磁流体尖刺 / ferrofluid spikes
  • Frutiger Aero 水感 UI / Frutiger Aero aquatic UI

这些词的价值在于，它们更接近图像生成模型能理解的视觉线索：

  • 材质
  • 年代
  • 媒介
  • 光线
  • 空间
  • 印刷方式
  • 影像缺陷
  • 亚文化气质

这个 skill 是怎么工作的？

它的核心组合逻辑很简单：

主体 subject + 主风格 base_style：1 个 + 材质/光色 surface_or_light：0-1 个 + 版式/空间 format_or_space：0-1 个 + 媒介缺陷 defect_layer：0-1 个 + 反跑偏约束

默认 prompt 骨架是：

比如你给它一个主体：

陶瓷猫香水瓶

Codex 就可以自动调用 skill，从风格库里随机抽取组合，生成一组完全不同方向的 prompt。

它可能把这个主体变成：

  • 复印朋克传单里的产品广告
  • 邵氏武侠棚拍风格的奇幻道具
  • Frutiger Aero 水感 UI 里的拟物图标
  • 昭和喫茶店桌面上的复古商品
  • PS1 低多边形恐怖游戏里的关键物品

这件事的意义远远超过“帮你写 prompt”。

更重要的是，把风格探索从手工灵感，推进到自动化实验。

风格探索的真正意义

我希望这个 skill 能帮大家做三件事。

第一，减少重复。

不要每次都从老 prompt、老风格、老套路开始。很多创作者有审美，但启动时的风格词太少，结果一直在同一个审美池里循环。

第二，扩大风格雷达。

你平时可能不会主动想到“银盐展览墙标”“日本唱片侧标 OBI”“传真机热敏纸”“中世纪药房标签”“儿童电视动画赛璐璐”。但它们一旦和你的主体组合起来，就可能打开一个完全不同的方向。

第三，把灵感变成系统。

灵感不应该只靠刷图偶遇。它也可以被组织、被抽样、被批量实验、被筛选、被沉淀。

AIGC 创作接下来会越来越像实验室。

我们不只问：

这张图怎么变好看？

还要问：

这个主体还能进入哪些视觉系统？

它能不能变成玩具？
能不能变成电影海报？
能不能变成旧杂志广告？
能不能变成低多边形游戏道具？
能不能变成复印传单？
能不能变成昭和咖啡馆招牌？
能不能变成软胶收藏品？

当 Codex 负责自动化组合，GPT-Image 负责视觉生成，创作者真正要做的是判断：

哪个方向有生命力？
哪个方向值得继续发展？
哪个方向能变成系列？

进阶玩法：把 Codex 变成自动风格探索机

这个 skill 最有意思的地方，远远超过手动生成几条 prompt。

更大的玩法，是结合 Codex 的自动化功能，把它变成一个持续运行的风格探索系统。

比如我的设置是，每天晚上睡觉前开启 每 15 分钟生成 5 张图 持续跑一整晚：

然后当第二天你早上醒来，就会收获一大波神奇的图。

它们可能是惊艳的。

也可能是诡异的。

可能是抽象的。

可能是完全不符合你原本预期的。

但这正是它的价值。

因为每一张图都有可能打破你的认知边界，让你看到一个原本不会想到的方向。

有些图可以直接用。
有些图可以作为系列的起点。
有些图虽然失败，但暴露了一个有意思的材质、构图、光线或媒介方向。
有些图甚至会让你意识到：原来这个主体还可以这样做。

这是一种自动化灵感采样。

我真正想解决的问题

我不想再让大家一味玩老东西。

老风格当然可以继续用，但我们需要更大的风格探索半径，VSC社区和各位VSCer要一起进步。

AIGC 的优势，不该只停留在更快复制已有审美。它还可以帮助我们更快穿越更多可能性。

过去，一个创作者要探索 100 个视觉方向，可能需要查资料、看图、手动写 prompt、反复试错。

现在，Codex 可以帮你组织风格库、自动组合 prompt、定时生成、保存结果、辅助复盘。

GPT-Image 负责把这些组合变成图像。

你负责做最后也是最重要的判断：

什么值得继续？
什么只是噪音？
什么可能变成新的风格资产？

这就是 rare-style-explorer 的意义。

它的目标不止是多生成几张图。

它要把风格探索变成系统，把灵感发现变成流程，把创作者从老 prompt 的惯性里拉出来。

每天晚上让机器替你探索边界。每天早上醒来，看看世界还能长成什么样。

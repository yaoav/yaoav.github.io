四个岗位交给一个 AI 导演：我用一部手机实测了 Renoise

发表于2026-11-20|行业观察
|浏览量:

本文转载自 X 博主 @TuyetloanP81840（Miller） 的长文，原文链接，版权归原作者所有。

一个人拍 AI 视频，要同时当编剧、分镜师、抽卡师、剪辑师。这次我测了一个反过来的工具：四个岗位，交给一个 Agent。

它叫 Renoise，官方的说法是「口袋里 AI 导演」。这篇是我的完整测评：它能做什么，我实际用下来怎么样，上手前要注意什么。

一、Renoise 是什么

一句话：一个装在手机里的 AI 视频 Agent。你跟它聊天说想法，它从策划、角色、分镜、生成，一路做到剪辑包装，最后交给你一条能直接发、也能直接投放的成片。哪里不满意就跟它说，它改到你满意。

想边看边试的，可以先从这里下载（手机点开是 App，电脑点开是网页版）：

https://renoise.onelink.me/Gxyb?pid=xcom&c=tuyetloanp81840-chen-202611&af_web_dp=https%3A%2F%2Frenoise.ai%2F%3Futm_medium%3Dxcom%26utm_source%3Dtuyetloanp81840-chen-202611

把我那四个岗位放进来对照：

  • 编剧：以前自己想选题、写剧本、改台词 → 现在你说想法，Agent 写稿、做策划
  • 分镜师：以前拆分镜表，定人物、场景和镜头 → 现在 Agent 出角色和分镜
  • 抽卡师：以前写提示词，在几个模型之间来回抽 → 现在 Agent 调用内置的 43 个模型生成
  • 剪辑师：以前导进剪映，剪辑、字幕、配乐、导出 → 现在 Agent 剪辑、包装、渲染一起做完

别的 AI 视频工具大多只管第三步：生成素材。生成完，你还得打开剪映自己剪、自己配字幕。Renoise 最大的不同在最后一步：剪辑包装它也一起做完。

上手前先知道三件事：

  • 下载要海外账号：大陆苹果商店搜不到，需要海外 Apple ID；安卓用海外 Google Play。官方有注册教程，照着做一遍就好，链接放在文末。
  • 聊天不花积分：聊想法、改方案免费，只有生成素材和剪辑才扣积分，剪辑按实际用量扣。
  • 会用 Skill：官方把常见视频的做法写成了 Skill，直接说「用 XXX Skill 帮我做一条……」就行，不用自己找入口。

二、我拿它做了什么

我没拿它做随手的测试片，而是挑了三个真实会用到的场景，各做了一条：

  • 一条数字人口播：只用了我的一张自拍和一段声音
  • 一条 15 秒的 IP 手办宣传片：只给了一张形象图和一句话
  • 一条 30 秒的电影预告片级燃剪：题材是我原创的一只深海巨兽「渊」，在风暴海面上和一支舰队遭遇，分三段

预告片、游戏宣传片、短剧片头，这类片子以前要一个小团队来做：美术出设定，分镜拆镜头，特效出画面，剪辑卡点配乐。我想看看，一个人加一部手机能做到什么程度。

下面一条一条说。

三、功能实测

1. 数字人口播：一张照片，一段声音

我先测的是 Renoise 主推的数字人。素材只有两样：一张我的自拍，一段我自己的声音。

我让数字分身念的，就是一段介绍 Renoise 的口播：

别再打开剪映了。在 Renoise 里，你只管说想法，出镜、剪辑、字幕它全包。哪里不满意，点一下就改；聊天还不花积分。顺便说一句——跟你说话的我，是数字人。

它先用我的声音生成配音，这一步花了 20 积分。

配音出来以后，有个细节让我挺意外：它自己先核对了一遍，确认一个字都没读错；又发现每句之间空了一秒左右，听着拖，就自己把停顿收紧了。这两件事我都没提要求。

接着是对口型。它连表情都安排好了：开头语气认真，列举卖点时跟着节奏轻轻点头，说到最后「是数字人」时嘴角带点得意的笑。720P，这一步 182 积分，在卡片上确认了才开始扣。

成片里的字幕和关键词高亮也是它自动加的：「剪映」「说想法」「不花积分」这些词会变色放大。讲到「点一下就改」的时候，数字人还抬手推了一下眼镜。

数字人的语速天生偏慢一点，这条我把整体加快到了 1.2 倍，听起来更像真人说话的节奏。一个小建议：做数字人时，直接在给 Agent 的提示词里写上语速要求，比如「语速比正常稍快」，或者成片后让它把整条加快，比事后自己去剪省事。

我的评价：以前真人出镜要化妆、布景、对着镜头录，口误了重来；现在分身做好，每天只要换一段稿子。

2. 一张 IP 形象图，出一条 15 秒手办宣传片

第二条测的是商家最常见的场景：手里只有一张图，要一条能拿出去的宣传片。

我上传了自己的 IP 形象 Mili，只说了一句：「这个是我的 IP 形象图，帮我做成一段 15 秒手办宣传片。」

它先认出了形象的特点：白色毛绒小团子配橙色耳机。然后自己定了方案：横屏 16:9，15 秒，五个镜头一气呵成。暗场里一束暖光亮起，镜头贴近拍毛绒质感和耳机；脸部特写，大眼睛里闪过一道光；手办在展示转台上慢慢转一圈；再和橙白配色的开窗礼盒同框；最后定格在正面，肚子上的「Mi li」清清楚楚。这条花了 240 积分，生成用了 1 分 15 秒。

还有一个细节：生成出来的视频自带配乐，和一首已发行的歌撞了，被系统自动去掉。Agent 没让我自己处理，直接换上了一段可以放心商用的轻快 lo-fi。做商单的人都知道，音乐版权是最容易踩的坑。

我的评价：分镜、运镜、配乐都是它自己定的，我只给了一张图和一句话。门店、品牌、做周边的，产品图拍好就能出宣传片。默认出的是标清，要投放或者大屏播放，可以再让它放大到高清。

3. 电影预告片级燃剪：43 个模型，在一个对话里切

Renoise 内置了 43 个视频、图片和音频模型，包括 Seedance 2.5、Kling 4.0、Wan 3.0、GPT Image 2.5、Nano Banana、Midjourney，新模型 24 小时内上线。不用一个个平台去注册，也不用配 API key。

做燃剪之前，我先跟它把风格聊透：色调、质感、镜头语言，巨兽长什么样，哪些东西一定不能出现。这一步不花积分，我聊了 3 轮才开工。

然后先用 GPT Image 2.5 生成了四张参考图：巨兽三视图、巨兽细节、舰队设定、风暴海面。后面每一段视频都挂上这几张当参考，巨兽才不会每个镜头长得不一样。

视频交给 Seedance 2.5，要的就是浪头、水花和巨兽出水时的重量感。30 秒拆成三段，每段 10 秒、三个镜头，提示词沿用我抽卡篇的分段框架：参考素材、段落目的、分镜头描述、开场承接、结束帧交接。

我用的是 720P，一段生成一次 320 积分。想先看方向对不对，可以先出 480P 样片，一段 160 积分，定了再出 720P。都是在卡片上确认了才扣。

我的评价：以前我在几个平台之间来回导文件、来回抽卡，现在资产图、提示词、生成结果都在同一个对话里。方法还是那套方法，只是执行交给了它。

四、另外两个值得知道的功能

数字人上面已经实测过了。Renoise 主推的另外两个功能，做号的人一定用得上：

  • 口播剪辑：自己拍好的口播原片直接交给 Agent，它会去掉口误和停顿，配上字幕花字，补画面、配音乐，剪成一条能发的成片。你只管对着镜头讲，剪辑交给它。适合知识号、资讯号、老师讲课。
  • 爆款复刻：小红书、B 站、X、TikTok、Instagram、YouTube 上的爆款，复制链接给它（抖音暂不支持）。它只借结构、节奏和画风，人设、文案和素材全部换成你自己的。

营销场景也一样：门店、工厂、品牌的老板不想出镜，拍一张照片、录一段话就有数字人，门店号、产品号、老板号天天更新。做外贸的，一套口播出多个语种，不用再花几百美元请外国演员、等一周。

五、省积分的四个习惯

  1. 先聊透再开工：聊天不花积分，生成了再推翻才是真花钱。
  2. 大部分视频用 Wan 3.0 就够：质量好又省，比 Seedance 2.5 同档便宜 62%，数字人口播首选。
  3. 要质感再上 Seedance 2.5，先出 480P 样片：方向对了再出 720P，或者放大到 1080P。
  4. 尽量用推荐的 Skill：做法都写好了，出片更稳，返工少很多。

六、真实感受

用下来最大的感受是：我从「干活的人」变成了「提要求的人」。

好用的地方

  • 剪辑包装一起做完，不用再开剪映
  • 手机上随时做，排队、等车就能把方案聊完；回到电脑打开网页版，项目接着做。成片哪里不满意，在画面上点一下就能改
  • 聊天不花积分，敢多改几版
  • 生成前都有确认卡片，花多少积分心里有数
  • 它会自己把关：核对配音有没有读错字、收紧拖沓的停顿、检查画面和原图是否一致、自动换掉撞了版权的配乐，这些我都没提要求

上手前要知道的

  • 下载需要海外账号，照官方教程做一次就好
  • App 内暂时没有语音输入，用输入法的语音代替
  • 剪辑按实际用量扣积分，开始前只能预估一个范围
  • 数字人语速偏慢，提示词里写上语速要求，或者让 Agent 把成片加快

适合谁：想一个人起号、批量起号的自媒体；不想真人出镜、又要天天更新的商家和品牌；一条口播要出多个语种的外贸卖家。

如果你和我一样是一个人做内容，它替你分担的是最花时间的那部分。你要做的，是想清楚要什么。

Polymarket AI V2 交易系统：原理 + 实现

发表于2026-11-15|交易策略
|浏览量:

第一代的只是一代根据策略执行的机器人，高度依赖于策略，对外界感知力不足，（比如最近BTC大跌很多宏观原因它不会感知）这次加入了新闻扫描+大模型分析

第一部分：原理篇

1. 这套系统赚什么钱

预测市场有两个可利用的东西：

  1. 信息差：市场还没消化新闻、资金流、情绪、事件进展
  2. 定价偏差：市场价格 ≠ 真实概率

系统只做一件事：

用多渠道信息判断”真实概率 P”，再和市场价格比，只有 P 明显高于/低于价格时才下注。 数学公式负责”买哪个、买多少、什么时候卖”，不负责”猜方向”。

一句话：基本面找机会，公式管执行。

2. 旧版本为什么亏

旧策略结果原因做市 V1-1.551~2 分价差 < 手续费+滑点做市 V2-0.23逆向选择，被知情者成交scalp-0.21同上天气 AI 回测负公开天气数据打不过市场实盘做市-0.30 熔断微亏累积，参数救不了结构

核心教训：

  • 纯数学公式在有效市场里找不到漏洞
  • 小价差策略长期被手续费吃光
  • 真正的 edge 来自”事件 + 信息 + 人怎么想”

3. 系统总览（五层）

4. 怎么想（思考框架）

分析任何一个事件，按这五步走：

4.1 事件成立的必要条件

列出”要发生这件事，必须先满足哪些条件”。

例：BTC 跌破 66,000

  • 现货必须跌到 66,000 以下
  • 时间必须在结算时刻（币安 1 分钟收盘价）
  • 期间不能出现大反弹

4.2 已经出现了哪些条件

  • 现价距离阈值多少
  • 24h/7d 动量
  • 资金流：ETF 流入/流出
  • 情绪：恐惧贪婪指数
  • 新闻：利好/利空/催化剂

4.3 反证与阻力

  • 什么情况会让判断失效
  • 极端恐惧也可能是底部（反向指标）
  • 市场可能知道你不知道的事

4.4 给出概率 P

  • P ≥ 60% → 考虑买 YES
  • P ≤ 40% → 考虑买 NO
  • 40%~60% → 不参与（没有优势）

4.5 写下失效条件

  • 出现什么信息就必须退出
  • 什么时候必须重新评估

5. 怎么决策（概率与公式）

5.1 模型概率

对”到期时价格高于 K”的市场：

代码块

  • S：现价
  • K：阈值
  • σ：日波动率（近期已实现波动，取短/长窗口较大值）
  • T：剩余天数
  • Φ：标准正态分布函数

5.2 因素调整

因素调整方向24h 暴跌 ≥3%下调”高于”概率恐惧贪婪 ≤25下调利空新闻 ≥2 条下调24h 大涨 ≥4%上调贪婪 ≥75上调

只有 Edge 足够大才交易；系统阈值 10%。

5.4 凯利仓位

单笔上限 2 USDC（彩票模式 1.2 USDC）。

5.5 什么时候卖

  • 价格涨到接近你的 P → 卖出
  • 出现反证、P 下降到 50% 以下 → 退出
  • 彩票模式：涨到 2.5 倍或跌 50% → 自动平仓
  • 到期前结算，赢的自动赎回

6. 两种交易模式

6.1 事件价值投注（正期望，主策略）

  • 概率 ≥60% / ≤40%
  • 每笔 1~2 USDC，最多 2 仓
  • 持有到结算或止盈止损

6.2 尾部彩票（小概率高赔率）

触发条件（满足其一）：

  • 24h 跌幅 ≥1%
  • 恐惧贪婪 ≤15

筛选：

  • BTC 日线阈值低于现价 3%~10%
  • No 价格 ≤15¢
  • LLM 判断 No 概率高于市场价

执行：

  • 每次 1.2 USDC
  • 最多 2 个持仓
  • 涨 2.5 倍或跌 50% 自动平

这就是暴跌 + 极度恐惧时，市场低估继续下跌尾部概率的机会。

16. 升级对比（旧 → 新）

17. 最小可运行流程

  1. 配好 .env
  2. 跑 news_scanner.py、macro_scan.py 确认抓得到数据
  3. 跑 crash_scan.py 确认能列出机会
  4. 跑 value_bet_scanner.py 确认有 edge 输出
  5. 用只读/小额验证
  6. 开 1.2 USDC 彩票单试水
  7. 看 logs/lottery.log、面板成交
  8. 有成交后跑 reconcile_live.py 对账

18. 复刻最容易踩的坑

  1. 私钥/API key 泄露：只放 .env，不提交、不发聊天
  2. 签名类型：代理钱包常用 signature_type=2，错了报 invalid signature
  3. neg_risk：部分市场要 neg_risk=True，从 Gamma 市场字段读
  4. 最小单：市价单最低 1 USDC，金额精度 2 位
  5. 结算源：BTC 日线市场看币安 1 分钟收盘价，不是 Coinbase
  6. 时区：结算 ET 正午 = 北京次日 01:00
  7. 手续费：taker 有费，maker 0；小价差策略会被费吃光
  8. 过度拟合：别拿回测当实盘，先小仓验证

19. 每日流程

早上

  1. 看面板权益、持仓、成交
  2. 看 reports/intel/news.md、macro.md
  3. 看彩票/价值机器人日志

触发条件出现时

  • 暴跌/极度恐惧 → 检查彩票仓位
  • 大新闻 → 让 LLM 重新评估相关持仓

晚上

  • 21:00 巡检报告
  • 复盘当天交易：赢在哪、输在哪、概率判断是否偏差

20. 铁律

  1. 单笔不超过 2 USDC，彩票不超过 1.2 USDC
  2. 概率 40%~60% 不交易
  3. 不因为”跌得猛”就重仓
  4. 出现反证立刻退出，不补仓摊平
  5. 不把 API key/私钥发到聊天里
  6. 亏损后不急着回本，先停一天
  7. 记录每笔交易的理由，方便复盘

为什么非英伟达（N）卡不可？

发表于2026-11-15|行业观察
|浏览量:

本文转载自 X 博主 @Elicellove（elise） 的长文，原文链接，版权归原作者所有。

在说算力租赁的时候，有人说英伟达卡没前途是废品，拥抱华子。我想说的国产GPU与英伟达GPU还是有代差的，没个3到5年赶不上，其实也许需要更长时间。这也是算力租赁公司的核心业务价值，正因为国内缺高端英伟达卡，这些算力租赁公司搞到了高端的卡运维服务，供给大厂和国内大模型公司，从而获得丰厚的报酬。现在主要看17号英伟达的财报，国会对黄仁勋的认定，算力高增速还能不能讲下去。算力租赁毕竟国内对英伟达高端卡需求还在，海外链要是没看增速，那些更难。

为什么国内云厂商不自己搞，主要还是做了一些风险隔离和财务上的优化，毕竟买设备是重资产，对资产负债表不利！

下面说一下原因，正式科普来了。

为什么国内云厂商（CSP）优先选用N卡，国产卡现阶段只能承接部分特定负载？

如果这个底层逻辑没看懂，很多推演都会偏离事实。不少人会简单理解成：N 卡受限买不到，国产卡自然就能大规模替代。但这个非黑即白的判断并不成立，我们可以从芯片、互联、软件、综合成本四个维度拆开来看。

AI 芯片的硬实力，核心由三点决定：制程、HBM 显存、先进封装。

制程上，国产主流芯片依托DUV多重曝光实现国内7nm级工艺；英伟达 Blackwell 基于台积电 4nm，下一代 Rubin 推进至 3nm，两代制程差距，直接带来晶体管密度、能效比的巨大鸿沟。

HBM 显存带宽，决定大模型训练、推理的吞吐能力，本质就是单位时间内向计算单元传输数据的能力，英伟达已经用上 HBM3E，后续将升级 HBM4，国产芯片只能使用更早一代的 HBM，供给还持续紧张，寒武纪此前业绩不及预期，核心原因之一就是 HBM 缺货。

落到单卡对标来看，寒武纪思元 590 大致对标 A100，升腾主力型号对标 Hopper，对比当前主力出货的 Blackwell Ultra，中间隔着 2～3 代，代差带来功耗效率差距巨大，从商业角度，厂商不会主动大规模采购能效落后的芯片。

互联能力，是比单卡更致命的短板。大模型训练需要把任务拆分到数万张卡同步计算，每一轮都要跨卡同步梯度，集群整体性能，瓶颈往往不在单卡算力，而在卡间通信。英伟达采用分层方案，机柜内依靠 NVLink 做 scale-up，最多 72 张 GPU 组成共享内存的一体化集群，等效一台超大规模机器；机柜之间通过 InfiniBand 或者高速以太网 scale-out，串联海量机柜。国产芯片普遍缺少 scale-up 这一层高速互联能力，高速 SerDes、交换芯片配套不足，只能靠 scale-out 简单堆卡。堆卡的代价非常明显：卡数量越多，通信开销占比越高，集群有效算力无法线性增长；同时大规模长周期训练，只要任意节点故障，任务就要从检查点重启，单卡可靠性不足时，前沿训练任务很难稳定跑完。

再看软件生态，CUDA 从来不是简单的编程接口，是英伟达十几年沉淀下来的算子库、编译器、性能调优工具组成的完整生态。学术界、大厂提出新模型结构，在 N 卡上往往可以快速验证、直接跑通。

换到国产卡，新模型用到的大量算子大多没有现成实现，需要工程师逐个移植、调优，还要对齐精度与性能。对于迭代速度极快的云厂商和大模型团队，几个月一轮的模型更新，这个适配时间成本很难承受，适配成功，只代表 “能跑”，不代表好用、划算。最后是综合 TCO，云厂商采购算力，不看单卡标价，核心核算全生命周期成本，把硬件折旧、电费、机房、运维人力全部折算，看每输出一个 Token 的成本。

国产卡单卡售价更低，但单卡产出 Token 更少、能效更差，同等算力需求下，需要占用更多机柜、消耗更多电力，还要投入额外工程师做适配优化，综合摊薄之后，国产卡单 Token 成本普遍高于 N 卡。

现阶段国产芯片的优势场景，是权重固定、算子一次适配就能长期复用、时延容忍度更高的推理业务，比如推荐、搜索排序、内容审核，以及固定版本大模型推理。这类需求体量不小，叠加国产芯片原本基数很低，寒武纪累计出货也就十几万颗级别，所以近几年增速看上去非常亮眼。但前沿大模型训练、新模型大规模推理，这类算力需求的核心场景，目前仍然高度依赖 N 卡。

网上经常能看到国产芯片适配各类大模型的消息，适配只是 “跑通”，不等于具备商业性价比，更不等于大规模采购。国产芯片增速很高，但出货绝对数量、整体金额占比，其实远低于很多人的预期。我并不是看空国产芯片，未来如果 HBM 供给、先进制程产能持续打通，局面会发生根本性变化；往后几年国产芯片依然会保持高速成长，芯片本身、配套生态都会持续迭代，国内算力需求也在持续扩容。

只是我们要分清：高增长≠高占比，当下国产算力的体量，还远没有到可以替代 N 卡的量级。

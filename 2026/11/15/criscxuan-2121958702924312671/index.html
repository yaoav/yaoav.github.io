腾讯上线「鹅次元」私人游戏陪伴式 Agent，太会玩儿了

发表于2026-11-15|行业观察
|浏览量:

本文转载自 X 博主 @criscxuan（cxuan） 的长文，原文链接，版权归原作者所有。

前两天在 x 上分享的鹅次元没想到爆了，看来大家兴趣很高，于是我今天实测了一下。

这是腾讯 QQ 出的首款专属 AI 游戏陪伴 Agent。

面向端游玩家，提供拟人化 AI 陪伴和实时语音互动。

可以实现在 PC/QQ 内部进行聊天。

还可以作为桌宠、一键换装、嘴替变声等有趣玩法。

最下面会有不同女生的介绍，而且每个女生性格不同，有 ENFP、INTP、INFJ 和 ESTP ，这个大家最好实际体验下哈哈哈。

目前只能使用 QQ 登录，而且只支持 Windows 版本，Mac 不支持。

猛的一看好像有点违和感，现在还有啥 Agent 能不支持 Mac ？但你细想一下好像也没错，你会用 Mac 来玩游戏吗？

于是我就拿出来我那个积灰已久的 Windows 本了，终于有了用武之地。

客户端下载完了。

鹅次元我来了，哈哈哈。

我倒要看看你怎么懂我。

不过问题来了，为啥上面 QQ 登录之后 ，下载完成后又提供了两种登录方式，什么鬼？？？

闹了半天我才明白，上面的 QQ 登录，只是内测资格，因为现在还是元气首测阶段。。

OK ，登录之后会填用户信息。

填完之后就来到 LSP 狂喜的环节，选人物！，目前只有四个女性角色可以选择，暂时还不支持男性角色。。。

尼玛，我可是喜欢男的确实不错啊。

目前有四个女性角色，夏夏、沈露白、谷雨、贝拉，我不知道这四个人物在网上是有原型吗？懂得小伙伴可以说一下。四种女性角色对应不同的性格应该是。

然后我选了沈露白这个角色 ，一进门，哦不是，一进来之后这个场景就有点意思了。

别想太多，鹅次元是主打游戏陪伴的 Agent ，相当于是你的游戏搭子，目前支持四种游戏。

最近的爆火的影之刃零也在其中。

在玩游戏过程中，AI 伙伴会在合适的时间说合适的话。

甚至输赢都能够在合适的时候说合适的话。

而且如果你有关于游戏的疑问时，她会基于公开的知识和一般性战术给你解答。

比如，这是 AI 角色训练后自己生成的影之刃零的攻略图，质量已经非常在线。

点击左侧的时刻支持换肤，有不同的场景可以选择，emmm 。。。

换了个场景，随随便便聊了两句。

麻的，我这么由衷的赞美她，她竟然说我说话直接，真是不食人间烟火，不知道简单一句牛逼是这个世界上最荣耀的赞誉吗？？

目前还支持语音，你也可以给游戏 Agent 打电话聊一下。

我是真没懂为啥沈露白会喜欢猫。。。谷雨和夏夏喜欢我倒是不难理解。

没有喜欢小狗角色的么？？？

除此之外，你还可以加对应角色的好友，从而实现在 QQ 上跟她继续聊天。

总之体验了一圈我给它的定位是，这是个让你打游戏没那么无聊的游戏 Agent 。

这不是真人陪玩，做不到陪玩那样的随叫随到。

但她是一个游戏里面的专业 Agent ，人物的训练基于腾讯游戏自研模型和游戏知识库。

她能在合适的时间说合适的话。

她懂游戏，她也可以更懂你。

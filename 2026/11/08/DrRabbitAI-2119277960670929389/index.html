国自然放榜后，我又动心了：我让Codex整理了25100个获批项目题目

发表于2026-11-08|行业观察
|浏览量:

本文转载自 X 博主 @DrRabbitAI（Roxy） 的长文，原文链接，版权归原作者所有。

大家好啊，我是兔老师。

国自然放榜，我认真看了一下今年的数据。

2026年集中接收的10类项目，一共资助69,563项。
2025年是53,159项。也就是说，今年增加了16,404项，增幅约30.9%。

其中，两类和青年教师关系比较密切的项目，变化尤其明显：

青年科学基金项目（C类）：增加12,046项，增幅50.1%；

面上项目增加3,400项，增幅14.8%。

看到这个变化以后，我又动心了。

刚好最近，北京市自然科学基金2026年第三批项目申请也启动了。

一边是国自然青年C和面上项目扩容，一边是北京市自然科学基金正在申报，再加上现在已经可以用AI辅助做选题调研、查文献和整理材料，我又萌生了申请项目的想法。

申请项目的第一步，当然是「找选题灵感」。

我要把过去获批的国自然项目整理出来，看看大家都在研究什么。

01｜为什么我要收集历年的获批题目？

准备基金选题的时候，我们经常会去看历年的获批项目。

倒不是为了照着别人的题目改几个词，而是想知道：最近几年哪些问题正在受到关注，大家在研究什么对象、什么机制，又在使用哪些新的研究方法。

我们可以从这些题目里观察研究趋势，再回到自己的研究基础中，寻找可能的切入口。

另外，我想插播一句。

历年的国自然和国社科获批项目，其实也是非常好的硕士、博士论文选题库。

基金项目通常比较大，硕士和博士可以从里面拆出一个具体研究对象、一个作用机制或者一个应用场景，再把它缩小成自己能够完成的论文问题。

所以这批数据，不只适合正在准备基金的老师。对于刚开始找论文选题的硕士生和博士生，也很有参考价值。

02｜用惯Agent以后，我已经用不会传统查询网站了

决定收集数据以后，我先去了国自然官网。

官网当然可以查项目，但是它更适合查询某一个具体题目、负责人或者关键词。如果我想了解某一年、某个研究方向都有哪些项目，就需要不断输入关键词、设置筛选条件，再一页一页翻结果。

后来，我又去小红书上做了一轮调研，找到了一些可以查询国自然项目数据的网站。

这些网站不能说没有用，但都不是我想要的使用方式。它们的基本流程通常是：

选择年份 → 选择学科 → 选择项目类型 → 输入关键词 → 继续筛选 → 一页页翻结果

说得刻薄一点，我当时真的有一种在使用「上个世纪的网站」的感觉。

可能是Codex、Claude Code用得太多了，我现在非常不习惯这种操作方式。我不想先猜出所有关键词，也不想在几十个筛选项里反复选择条件。

我更希望直接用人话告诉Agent：

帮我找出2025年国自然获批项目中，和人工智能、大模型、智能体、多模态相关的项目。
按照研究主题分类，再结合我的研究基础，分析哪些方向值得继续调研。

03｜既然现成的网站不好用，那就自己DIY一份

因为平时Codex和Claude Code用得比较熟，我觉得这种数据采集任务，自己应该可以完成。

于是，我决定DIY一份真正适合自己使用的数据。

我把完整任务直接交给Codex我当时给Codex的任务大概是：

帮我调研公开可查询的国自然项目数据，评估哪些数据源适合进行结构化整理。
我想收集2025年和2026年的获批项目，以及2024年和2025年已经结题的项目。
请先给出采集方案，再编写能够持续运行、断点续传的数据整理程序，最后清洗、去重，并导出Excel和Markdown文件。

最开始，我只想采集自己关注的方向，例如人工智能、媒体融合和传播效果评估。

后来一想，既然已经让AI干活了，为什么不直接把范围扩大一点？

如果只按照我预设的几个关键词去收集，很容易错过新的交叉方向。而且Agent跑一个学科和跑全学科，对我来说都不需要手工一条条复制。

所以，我后来干脆不再限定学科，而是在公开检索结果的范围内，尽可能整理全学科的项目数据。

自己可以用，其他专业的老师、硕士生和博士生也可以一起用。

【还有一个原因，当前codex是200刀的额度，月底还剩下大量token可以挥霍】

04｜真正开始以后，发现比我想象中复杂得多

我原本以为，这就是一个自动翻页、保存数据的任务。

真正跑起来以后，发现完全不是这么回事。

第一个问题：数据量很大，采集速度很慢很多网站有访问频率限制和反自动化机制，速度稍微快一点就会报错，所以整个采集过程非常慢。

第二个问题：任务需要断点续传任务不能每次中断以后都从第一页重新开始。Codex需要给程序增加断点续传，记录哪些页面已经完成、哪些数据还没有采集。

第三个问题：抓下来不等于可以直接使用数据采集完成以后，还要继续检查字段缺失。

截至今天，比较稳定、可以先分享的，只有2025年获批国自然项目数据。后续的数据，如果大家觉得需要。我陆续采集进行分享。

摘要数据也可以继续收集，但耗时会更长。所以第一版，我只保留了项目名称、负责人和承担单位，先解决「看方向、找题目和做初步分析」的问题。

为了不给数据来源网站带来不必要的影响，本文不介绍具体网站、接口和采集细节，只展示Codex完成任务的过程和最后的数据结果。

05｜第一批数据，一共25,100条

目前完成的第一批数据，包含25,100条2025年国自然项目公开检索记录。

这里先说清楚数据口径：

公开检索结果：27,119条
本次稳定保存：25,100条
当前覆盖率：约92.56%

所以，这份文件不能叫「2025年国自然全部获批项目」。更加准确的说法是：

2025年国自然项目公开检索结果，目前已经整理25,100条。

同一个项目可能同时命中多个主题，所以表格里的数量不能直接相加。这个结果也不是基金委官方学科分类，只是基于题目关键词完成的第一轮筛选。

06｜这批数据，我准备怎么用？

最简单的方法，当然是直接搜索关键词。

但如果只是把这个Excel当成另外一个搜索网站，其实有点浪费。更适合的用法，是直接把文件交给Agent，再用人话告诉它你想研究什么。

尽管我订阅了 CC 和 Codex，但是基金的数据分析和本子撰写，我更倾向用用的 Agent 是 YILA，主要考虑是 YILA接入了论文数据库，我可以边讨论边搜索论文写材料了。尤其是，我近期的研究方向是人文社科方面，Codex、CC 能查到的社科论文不全，而且无法看全文。

（这里有一个小 Tips，基金数据量比较大。大家投喂 Agent 的之前，还是先大概筛选一下。不然上下文太长。非常浪费 Token。尤其是如果你选择了 YILA 的 expert 模式。）

**用法一：**先从全量数据中筛选方向请只基于我上传的2025年国自然项目数据，筛选与人工智能、生成式AI、大模型、智能体和多模态相关的项目，并按照研究主题进行分类。

不要补充文件中不存在的项目。

**用法二：**结合自己的研究基础寻找交叉点我的研究基础是人工智能应用、媒体融合和传播效果评估。

请从这些获批项目中，寻找与我的研究基础可能形成交叉的方向。不要直接替我确定最终选题，先给出值得继续检索文献的研究问题，并说明每个方向与我研究基础的连接点。

用法三：把大课题拆成硕博论文问题硕士生或者博士生，也可以这样问：

我正在寻找硕士论文选题。
请从这些获批项目中筛选与我的专业方向相关的项目，并将范围过大的基金题目，拆成适合硕士论文完成的具体研究问题。
不要照抄原题，同时提醒我还需要继续核查哪些文献和数据条件。

这里还是要提醒一下。

基金题目可以帮助我们观察方向，但不能直接证明一个新题目具有创新性。特别是目前的数据还没有摘要，只看题目，很难准确判断一个项目具体研究了什么。

得到候选方向以后，还需要继续查近五年的文献，分析已有研究的矛盾点，再结合自己的前期成果、研究能力和数据条件进行判断。

AI可以帮我们扩大视野、整理信息和比较方向，但最后决定研究什么的人，仍然是我们自己。

最后

这件事本来只是为了给自己的北京市自然科学基金申请找一点选题灵感。

做着做着，我发现这批数据不只对我有用。准备基金的青年教师可以用它观察资助方向，硕士和博士也可以用它寻找论文选题的启发。

如果大家觉得有帮助，后面我会继续慢慢整理。

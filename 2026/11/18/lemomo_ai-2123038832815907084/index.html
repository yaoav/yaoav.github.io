开源 lemo-animi 定格动画Skill。一句话，让 Codex 做一支定格动画短片

发表于2026-11-18|行业观察
|浏览量:

本文转载自 X 博主 @lemomo_ai（Lemomo） 的长文，原文链接，版权归原作者所有。

做一支 40 秒的黏土定格动画：小企鹅学做煎饼。

就这一句话。agent 自己写故事和镜头表，用生图模型做出角色，布景和动作表，然后在代码里一格一格地让它们动起来；再用真实乐器采样配乐、加拟音，最后打开一个本地审片台修改，直到成片。

这是我今天新发布的开源项目 lemo-animi。是一个Codex和Claude都可以使用的定格动画插件。

下面八种材质、八支样片，每一支都是它自己从一句话开始做出来的。

一、lemo-animi 是什么

一句话，做一支定格动画短片。它是给 Codex 和 Claude Code 用的 agent skill。主要的用法是在 Codex 里做片，图用 Codex 自带的生图；Claude Code 配一个生图模型也能用。

  • 生图模型负责出角色设定、八格动作表、背景。
  • Python 把动作表切成一格一格，一拍二（或一拍三）排在布景上，再加运镜、接触阴影、光和调色。这一部分是定格动画的核心。
  • 每种材质是一个固定的风格包：提示词模板、光线、机位写法、配乐和拟音。
  • 用真实乐器采样写的原创配乐，每个接触都有拟音；需要的话加旁白和字幕。
  • 如果不满意成片，在审片台上停在哪一刻就在哪写意见，它逐条改完给你看新版，直到你点通过。

定格动画本来就是一格一格拍出来的，一顿一顿才是它的味道。

二、怎么安装

要先有：macOS 或 Linux，装好 ffmpeg（macOS：brew install ffmpeg），以及 Python 3.11–3.13 或 uv。（这部分在第一次制作的时候会帮你检查并且安装）

要旁白（在线配音）和审片台（本机开一个端口），Codex 得用允许联网、允许申请权限的模式。权限不够时，它会在开工前先停下来告诉你要放开什么。

第一次做片

第一次做片要联网，如果之前什么都没有安装过，那么下载约 1.7 GB：Python 运行环境（约 300 MB）和配乐用的乐器采样（约 1.4 GB，可断点续传），都放在 ~/lemo-animi-env。

这一步是自动的，agent 先把环境装好、检查通过，才开始向你提问。下载失败会告诉你原因并停下来等。

你回答完，它等下载装好、检查通过，再开始做片。已经装过的不会重复装；同一台电脑上的 Codex 和 Claude Code 共用这个环境，哪边先装好，另一边就不再下载。

三、8 种风格，8 支样片

每支样片都是 skill 自己从一句话做出来的，中文旁白和字幕。风格用中文名、英文名或 id 都行。

01 · 黏土定格 clay《波波的煎饼》

油性黏土捏的角色和布景，表情夸张、压扁拉长，最有喜感。

故事（53 秒）：小企鹅波波想抛出一张完美的煎饼，两次都失败，闭上眼第三次成了；粘在天花板上的那张掉下来，正好给了小老鼠。

02 · 纸艺立体定格 papercraft《会游泳的灯塔》

卡纸剪刻折叠的纸雕灯箱，一层层前后排开，逆光透亮，安静又梦幻。

故事（57 秒）：小狐狸提着纸灯笼出海，一个浪把灯打进海里；漆黑里，大鲸鱼把灯顶了回来。原来鲸鱼也怕黑。

03 · 铁皮玩具定格 tin《嘟嘟的发条》

印花铁皮冲压的复古发条玩具，一顿一顿地动；上紧发条就活，发条松了就停。

故事（55 秒）：打烊后的铁皮马戏团，小象顶球；抛得最高的那一下发条松了，它一顿一顿停住，球正好落在歪着的鼻尖上。

04 · 羊毛毡定格 felt《雪夜的小灯》

戳戳乐羊毛毡做的小动物和雪景，毛茸茸、安静、温暖，冷蓝夜色里点一盏暖灯。

故事（57 秒）：小兔子把灯留给怕黑的小松鼠，自己摸黑回家；走不动的时候，身后亮起了光。

05 · 纸板箱定格 cardboard《纸箱登月》

快递箱、胶带和马克笔搭出来的小孩想象世界，做得有点歪，一本正经地搞笑。

故事（58 秒）：纸箱宇航员登上月球、插旗敬礼；镜头一拉开，原来都在卧室地板上，「实际飞行距离：三十厘米」。

06 · 木偶定格 wood《灯下》

清漆木雕的关节木偶，深夜一盏油灯下，一个关节一个关节地活过来。

故事（55 秒）：刚刻好的小木熊在油灯下醒来，学站、被黑吓回来；灯芯矮下去时它拧亮了灯，光里还有一只小木兔也醒了。

07 · 钩织玩偶定格 crochet《噗噗鼓起来》

毛线一针针钩出来的玩偶和满屏小世界，糖果色、热闹、到处都在轻轻动。

故事（58 秒）：小河豚一激动就鼓成刺球，把小鱼全吓跑；大水流卷来时它主动鼓起来，小鱼们全躲到了它身后。

08 · 布偶拼布定格 fabric《豆豆抄近路》

花布、纽扣和针脚缝出来的布偶和田园，暖阳下走一段路，柔软又有乡土味。

故事（58 秒）：走在最后的小鸭走散了，顺着一道针脚穿过拼布田野、踩着纽扣过河；这一回，第一个到池塘的是它。

四、制作流程：从一句话到一支片

  1. 装好环境，所有问题（风格、时长、画幅、旁白、片头片尾）一次问齐，默认项排第一，也可以直接回「全部默认」。之后一路做到成片，中途只发简短进度。
  2. **先定方案。**故事骨架和每段秒数（交代、三次尝试、低谷、转机）、节拍、镜头表、生图清单。
  3. **生图。**角色设定、背景、八格动作表、2×2 近景表，透明底，全按同一种材质的样子。
  4. **代码让它动。**动作表切成一格一格，一拍二（或一拍三）排时间，再加运镜、接触阴影、光和调色。
  5. **配声音。**用真实乐器采样写的原创配乐，每个接触都有拟音；需要的话加旁白和字幕。
  6. **你来审。**它先自己审一遍、改一遍，再打开审片台交给你。

片子越长，镜头和生图越多：

  • 20 秒：2–4 个镜头，约 10–14 张图
  • 40 秒（默认）：5–8 个镜头，约 20–26 张图
  • 60 秒：6–12 个镜头，约 30–38 张图
  • 2 分钟：12–22 个镜头，约 55–68 张图

但是如果想要情节更加丰富和复杂，可以在开始的时候，提前要求故事情节。

你用什么语言写，它就用什么语言跟你说话；旁白、字幕和片头片尾是中文或英文。

成片默认 1920×1080（竖屏 1080×1920，方形 1080×1080），24 帧/秒，有原创配乐和拟音，放在 agent 于你的工作目录里建的片子文件夹中。

五、怎么用审片台

审片台：上面是片子，下面是按镜头排开的胶片，右边是意见。

片子做好后，agent 会在浏览器里打开审片台。用法一共四步：

  1. **停在要改的那一刻。**空格播放 / 暂停，← → 一帧一帧找。
  2. **按回车，写下看到的问题。**时间码、帧号和镜头会自动带上，胶片上会钉一枚图钉。
  3. **点「提交给 agent」。**agent 逐条去改，在每条意见下回复改了什么，再登记新的一版，页面会提示你刷新。旧版本和当时的意见收在下面。
  4. 满意了点「通过」，agent 交片。

**不用急。**页面顶上会显示 agent 是不是在等你、还剩多少时间，打开审片台后它最多等 30 分钟。过了时间也不要紧，什么都不会丢：

  • 意见边写边存在片子文件夹里，页面照样能用。
  • 写完点「提交给 agent」或「通过」，再回对话说一声「看完了」，agent 会读到全部意见，接着改。
  • 页面关掉了，就让 agent 重新打开审片台。
  • 如果审片台是以本地文件打开的（agent 的沙盒不让它起本地服务），点「复制意见」，贴进对话。

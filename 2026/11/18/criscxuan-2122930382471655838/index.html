REA 靠边站，逆向圈又一新王诞生了

发表于2026-11-18|行业观察
|浏览量:

本文转载自 X 博主 @criscxuan（cxuan） 的长文，原文链接，版权归原作者所有。

最近逆向工程和 AI 编程圈又迎来了一个极其亮眼的开源新项目，这个 GitHub 项目就是 craft-anything。

它的定位非常硬核：帮工程师彻底搞懂手头任何网站、应用或软件的底层结构与运行逻辑，然后直接基于理解，重新构建出一套属于自己的原生版本。

你只需要把目标交给它，定好想要的技术栈。

然后，你就等着就行了。

还记得前段时间全网刷屏的 REA（逆向一切）吗？如果说 REA 开启了全民逆向的风潮，那 craft-anything 就像是它的纯 Rust 工程化进化版。

项目一开源热度就直接拉满了，GitHub Star 短短时间内就冲破了 35K star，而且整个引擎用纯 Rust 编写，内存占用极低，跨平台跑起来非常丝滑。

这篇就跟大家聊一聊 craft-anything，以及它到底强在哪里、该怎么上手玩起来。

它和传统逆向工具到底有什么不一样？

提起逆向，很多人第一反应就是打开 Ghidra 或者 IDA Pro，对着满屏的汇编指令和反编译伪代码硬啃几天。

craft-anything 的切入维度完全不同——它不只盯着单点代码，而是站在观测取证 → 拓扑梳理 → 原生重构的全局视角，把整套流程直接做成了自动化的流水线。

你可以用非常自然的语言给它下达各种任务，比如：

  • 网站与前端应用 1:1 拆解与复刻：

“帮我分析这个目标网站（https://example.com）的页面布局、色彩字体、交互状态流与核心业务逻辑，使用现代 React + Tailwind 从零构建一个干净可维护的原生版本，并自动校验不同屏幕宽度下的还原度。”

  • 桌面客户端与打包产物架构梳理：

“对这个本地桌面应用包做结构与运行行为观测，梳理出它的模块划分、本地数据存储方式以及核心交互链路，输出一份结构清晰的模块化规范和骨架代码。”

  • 遗留系统与原生二进制深度分析：

“开启深度分析模式，结合符号解析与反编译工具检查这个二进制文件的内部模块依赖与核心状态迁移逻辑，梳理出完整的业务交互说明，并用 Rust 帮我重写一个独立模块。”

接到任务后，craft-anything 不会让大模型靠猜去脑补代码，而是严格按照官方设计的四步来执行：Study（观测取证）→ Build（动手构建）→ Check（比对校验）→ Ready / Refine（就绪并迭代打磨）。

具体来说，它背后有三个优势：

第一，内置了 320+ 工具。

craft-anything 用纯 Rust 封装了超过 320 个专门的分析与检测工具，覆盖网站 DOM 与视觉测量、Electron、Apple 应用、Android、.NET、Java、数据库、固件乃至游戏资源。而且这 320 多个工具，每一个既是独立的 CLI 命令，又是标准的 MCP 工具，可以直接喂给 Claude Code 这类 Coding Agent 调度。

第二，默认 Clean-Room，也保留了 Deep（深度模式）。

这一点设计得非常聪明，也直接回应了之前 REA 容易踩红线的问题：

  • Clean-Room 模式（默认开启）：只观测外部用户可见的信息——截图、DOM 结构、排版尺寸、配色字体、可见文本、菜单与交互流程，直接屏蔽掉读取原软件源码和内部文件的工具。不看对方一行源码，也能把交互与逻辑复刻出来。
  • Deep 模式（按需开启）：如果你分析的是自己团队的遗留系统、或者已获授权的私有软件，可以手动切到 Deep 模式。此时引擎会放开底层文件分析、ELF / Mach-O / PE 等可执行格式解析、符号解码，并支持联动本机 Ghidra 等反编译器做深度拆解（运行态隔离方面，Linux 上会配合 bwrap，Windows 上则用 Job Objects 来管住子进程）。

第三，看懂之后，直接帮你搞出来。

传统工具到出分析报告就结束了，但 craft-anything 会在 Study 阶段把散乱的页面信息、模块关系和交互事件流梳理成结构化证据链，再直接交给 Coding Agent 产出可运行的骨架与完整工程，最后还要回过头来自动 Check（比如对比多分辨率渲染效果、核对功能表现），有偏差就自动 Refine，把原本需要几天的分析 + 复现压缩到几分钟级别。

值得一提的是，craft-anything 并不是一个孤立的小玩具，它背后其实是 ArtCraft（storytold） 正在推进的一整套纯 Rust 开源创意与办公软件全家桶（The Craft App Suite）。

这帮人野心非常大，直接用原生高性能架构把日常惯用的商业创作软件几乎拉了一遍平替。。。

  • 平面设计与文档出版：PhotoCraft（支持图层、蒙版、文字与真实 PSD 文件编辑，对标 Photoshop）、VectorCraft（矢量插画）、LightCraft（照片库与 RAW 后期）、DesignCraft（版面排版与出版）、FigCraft（界面设计与原型，对标 Figma）、PdfCraft（PDF 阅读、整理与保护）。
  • 音视频与动态特效：FilmCraft（视频剪辑、调色与音频）、EffectCraft（动态图形与视觉特效）、SoundCraft（音频录制与剪辑）。
  • 3D 材质与 CAD 工程：CADCraft（CAD 辅助设计）、TextureCraft（3D 纹理绘制）、MaterialCraft（节点式程序化材质），再加上社区推出的参数化 3D CAD 应用 SolidCraft。
  • 日常办公与数据：WordCraft（文档处理）、DeckCraft（幻灯片演示）、GridCraft（电子表格与数据）。

而 Craft Anything 则是整套生态里最特别的那一个 meta tool ：前面十几款是官方亲自下场帮你把常用软件重做一遍；而 Craft Anything 直接把看懂软件并从零重造的引擎开源出来，让任何人都能自己上手去 Craft 一切。

如何使用

下面讲一下怎么把 craft-anything 跑起来。

它同时提供了桌面端 GUI、命令行工具（craft-anything-cli） 以及 MCP Server 三种形态，支持 macOS、Windows、Linux 和 FreeBSD，按自己习惯选就行。

  1. 环境准备
  • Rust 工具链：需要 Rust 1.97 或更高版本（建议提前 rustup update 一下）
  • 系统依赖（仅 Linux 编译桌面端需要）：Debian / Ubuntu 用户需要先装一下窗口与图形开发包：

sudo apt-get install build-essential libxkbcommon-dev libxkbcommon-x11-0 libwayland-dev libx11-dev libxrandr-dev libxi-dev libgl1-mesa-dev libgtk-3-dev

  • AI Coding Agent：本地提前配置并登录好支持接入的 Agent（比如 Claude Code）
  1. 下载安装包或源码编译

如果只是想快速体验，最省事的方式是直接去 GitHub Releases（目前最新为 v0.6.1）下载对应平台的预编译包——macOS 用户直接下通用版 .dmg 或 CLI .zip（均已签名公证），Windows / Linux / FreeBSD 也都有现成安装包。

如果你想从源码自己编译，再拉仓库执行下面的命令：

git clone https://github.com/storytold/craft-anything.git
cd craft-anything

方式 A：直接编译启动桌面端图形界面

cargo run –release -p craft-anything

方式 B：全局安装命令行工具 craft-anything-cli

cargo install –path apps/craft-anything-cli

  1. 验证与上手实操

装好之后，先跑一遍体检命令，检查 Rust 环境、反编译扩展以及本地连接的 Coding Agent 是否就绪：

craft-anything-cli doctor

体检全部通过后，你就可以直接开始手搓任何项目了。

比如在命令行里查看它到底自带了多少工具：

craft-anything-cli commands

直接对着一个目标地址下达复刻 / 改造指令：

craft-anything-cli rebuild https://example.com “用简洁的现代风格复刻这个页面，并把顶部导航改成深蓝色”

如果你习惯在自己常用的 AI 助手（Claude Code、Cursor 等）里直接用对话驱动，只需要把它作为 MCP Server 拉起来就行：

craft-anything-cli mcp

或者更偷懒一点，直接把仓库丢给你的 Coding Agent：

帮我检查本地 Rust 环境并编译安装 craft-anything（https://github.com/storytold/craft-anything），完成后运行 craft-anything-cli doctor 帮我确认配置是否正常。

真实体感

如果拿它跟前段时间的 REA 放一起对比，我的感触是：

REA 更像是一把手术刀，擅长把别人 App 的内部实现刨根问底给你讲明白；而 craft-anything 则是直接给你搭了一整座自动化重构工厂——用纯 Rust 把 320 多个探测工具打成底座，省资源、跨平台，还把 Clean-Room 净室复刻和 Deep 深度拆解分得清清楚楚。

不过实际玩下来，也有几个细节值得注意：

  1. 编译门槛比 Node 套件稍高一点：需要较新的 Rust（1.97+），第一次 cargo 编译会花一点时间，但跑起来之后确实稳。
  2. 注意区分规则隔离和内核沙箱：官方自己也说，默认的 Clean-Room 模式主要是规则层的工具拦截（防止 Agent 去偷看源码），如果你真要拿来跑来路不明的高危二进制，还是老老实实放到虚拟机或独立沙箱里更稳妥。
  3. 如果你特别看重架构可视化：craft-anything 更偏重“取证 → 写代码 → 校验”，如果你希望把梳理出来的业务流、模块拓扑画成高颜值的交互式图表，依然可以配合像 archify 这类架构图工具一起用，一个负责拆解重构，一个负责把逻辑漂亮地画出来，体验会非常完整。

总结

无论是学习优秀开源项目的设计思路、给老旧系统做私有接口兼容与协议对齐，还是看到一个惊艳的产品交互想用自己的技术栈重写一遍，它都能把原本动辄几天的分析与搭建工作，压缩到几分钟之内。

工具开源地址放在这里，感兴趣的同学可以直接去折腾一下：

  • GitHub：https://github.com/storytold/craft-anything

就像之前大家调侃的那样：以前是源码没公开就不算开源；现在有了 craft-anything，只要能运行、能被观测，几乎任何软件都能被你用自己的方式重新 Craft 一遍。

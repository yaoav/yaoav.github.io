超简单 X 收藏瀑布流插件，一键筛出你收藏里的百万爆款

发表于2026-11-18|行业观察
|浏览量:

本文转载自 X 博主 @momo_peggy（夏林果的出海日记） 的长文，原文链接，版权归原作者所有。

大家好，今天来看一个Chrome插件 X 收藏瀑布流 (X Bookmarks Grid) ！

你的 X 收藏夹，是不是收藏了就再也没打开过？

X 上的收藏越攒越多，想找回某一篇，只能在书签页一条条往下滑。

收藏了，等于没收藏。太奔溃了太难用了，上次还不小心，把收藏夹清空了，还好有备份，不然记录是真没了。

这收藏功能实在受不了，所以我最近做了个 Chrome 插件，专治这个毛病：把 X 收藏同步到浏览器本地，变成一面能搜索、能筛选、能导出的封面墙。

一分钟把上千条收藏变成封面墙！【如图管理页瀑布流全景】

一、它是什么

简单说，X 收藏瀑布流就是给 X 书签页配了一个本地资料库。

插件用浏览器里已登录的 X 会话读取收藏，存在本机，再用瀑布流的方式摆出来——每条收藏一张卡片，带封面、标题、作者、日期和浏览量。

和 X 自带的书签页比一下：

  • | | X 书签页 | X 收藏瀑布流 |
  • | :— | :— | :— |
  • | 浏览方式 | 单列，一条条往下滑 | 瀑布流，一屏看几十张封面 |
  • | 排序 | 只按收藏时间 | 收藏时间、发布时间、浏览量、导入时间 |
  • | 分类 | 不分 | 文章、视频、图片、纯文字、无标题 |
  • | 导出 | 没有导出按钮 | 单篇下载 Markdown，全库导出备份 |

为什么值得装？

收藏的东西找不回来，就不会再看第二遍。

插件首页写的那句话是：把好内容留给未来的自己。

二、下载安装

浏览器需要 Chrome 111 或更高版本来使用。

直接Chrome插件市场

安装地址：https://chromewebstore.google.com/detail/x-bookmarks-grid/bcnmpobkjmlpifdpmofoegopelcngkog?authuser=0&hl=zh-CN

源代码安装：

github 项目地址：https://github.com/xaiwind/x-bookmarks-grid

  1. 克隆或者下载压缩包，解压到一个固定的文件夹。
  2. 地址栏输入 chrome://extensions，打开右上角的 开发者模式。
  3. 点击 加载已解压的扩展程序，选中刚才解压的文件夹。
  4. 把插件图标固定到工具栏。

装完先做两件事：

  • 在当前 Chrome 里登录 X。 插件用的就是这个登录状态，不需要单独授权。
  • 点开弹窗，看一眼自动同步。 默认每天 01:00 同步一次新收藏，时间可以改，也可以关掉。

三、同步：点一下，剩下的不用管

点击插件图标，再点 打开我的收藏，插件自动开始同步。

第一次读取全部收藏，之后只读新收藏。

它是怎么读的？

插件在后台标签页打开 X 书签页，沿用 X 网页自己的请求，一页一页翻到底，读完自动关闭。不用滚动页面，不用守着。

几个让人省心的细节：

  • 每读到一页立即保存。中断、限流、关掉页面，已读到的都不丢，再点一次同步接着读。
  • 同步只新增或合并，按帖子 ID 去重，不会删除本地数据。
  • 30 分钟内不重复触发，不会反复打扰 X。
  • 旧记录的封面、标题想刷新一遍，点 完整重扫。

四、筛选·排序：几千条里捞出想要的那条

管理页打开就能用，几千条收藏也是立即显示。

分类： 文章、视频、图片、纯文字、无标题，五类互不重叠。每条收藏只属于一类，各类数量相加正好等于「全部」。

🔥 百万爆款： 一个开关，只看浏览量超过 100 万的帖子，可以和任意分类叠加。

想研究爆款怎么写的，打开这个开关，再选「文章」，就是一份现成的爆款文章清单。

搜索： 标题、作者、链接、备注都能搜。输入 @名字 直接搜作者，点卡片上的作者也能只看这个人的收藏。

排序： 收藏时间、发布时间、浏览量、导入时间。

两个快捷键：

另外还能按发布日期范围、是否含外链筛选。超过 3,000 字的普通帖子，卡片上会标「长文」。

五、右键卡片：五个操作

右键卡片，或者点卡片右下角的 ⋯：

  • 打开文章：新标签页打开原帖。
  • 同步文章：访问原帖，只更新这一条的标题和封面。
  • 编辑文章：改标题、加备注。改过的标题以后同步不会被覆盖，备注显示在卡片上，也能被搜到。
  • 下载文章：把正文转成 Markdown 文件下载，含标题、作者、链接、正文、图片链接和备注。
  • 删除文章：从插件里移除，可以立即撤销。

最值钱的是「下载文章」——好文章一键存成 Markdown，直接丢进 Obsidian、Notion 都行。

六、备份·换电脑

管理页点 导出备份，得到一个 JSON 文件。

换电脑、重装之后，点 导入备份 就回来了。

导入只补充缺少的内容，不会覆盖或删除现有数据。

七、隐私：数据只在自己的浏览器里

装这类插件，最该问的是数据去哪了。

  • 插件没有服务器。数据全部保存在当前浏览器本地，不上传，没有统计和广告。
  • 请求只发往 X 自己的网站，不访问其他任何网站。
  • 不保存 Cookie 和密码，不会替你发帖、点赞、关注或修改收藏。
  • 只保存标题、封面链接这类信息，不保存帖子正文。下载 Markdown 时，正文只写进下载的那个文件。

八、常见坑

坑一：升级点了「移除」，收藏全没了。

移除扩展会连同本地资料库一起删掉。升级只需要点扩展卡片上的 重新加载。保险起见，升级前先导出一份备份。

坑二：在插件里删除，X 上的收藏还在。

插件里的删除只动本地，不碰 X。反过来也一样——X 上取消收藏，本地那条还留着。

坑三：同步突然变慢。

X 改版后，插件读不到书签请求，会自动退回滚动页面的兼容模式，能读完，但速度慢。X 改版也可能让同步暂时不可用，等新版本。

坑四：卡片显示「无文字」。

只有图片或视频、没有文字的短帖，本来就没有标题，不是没同步上。

坑五：升级后数据没更新。

升级前就开着的 X 书签页，要刷新一次。

最后

收藏夹不该是内容的坟场。附上安装视频，大家快去安装吧！

装上插件，把攒了几年的收藏翻出来再看一遍，说不定下一篇爆款的选题就躺在里面。

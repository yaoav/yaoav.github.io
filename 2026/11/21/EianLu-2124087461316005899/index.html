我一个人用 Claude Code 做微信小游戏，一周广告赚了 1.6 万：评论区问得最多的问题，一次讲清楚

发表于2026-11-21|行业观察
|浏览量:

流量主后台截图：近 7 日 16,090.34 元，开广告以来累计 16,909.79 元

一个月前它刚开广告，第一天收入 3 块 6 毛 5。

还是那几句话：个人身份注册，没开公司，没花钱买量，代码全是 Claude Code 写的。

上周我写了一篇《从注册到开广告赚钱，七步讲清楚》，发出去以后，X 上每天几百条评论，问题一个接一个。我每天早上发一条收入，再把评论区的问题整理成「增补」帖，一周下来攒了一大堆。

这篇把它们全部收在一起，还是按那七步的顺序：

  1. 能不能做：备案多久、更新要不要再备案、认证和备案的区别、一个人能注册几个
  2. 注册：邮箱不够用怎么办
  3. 做游戏：用什么做、排行榜、数据后台、背景音乐、关卡太难怎么办
  4. 备案和提审：长表单和截图都交给 AI
  5. 开通流量主：游戏圈这条路更好走
  6. 广告：多少人玩能赚多少、插屏的一个小细节
  7. 流量：投流了吗、新游种子什么时候开、收入为什么会回落

第一步：能不能做

1.备案要多久？

两个备案（小游戏备案、小程序备案）前前后后，我大概花了十几二十天。

但纯单机、不联网的小游戏，备案没走完也能发布上线。我就是备案之前先上的。评论区有人问「两个备案都还在审，能上架吗」，答案是能，只要是纯本地的。

  1. 更新版本要重新备案吗？

不用。我提审时签了一份单机声明，之后可以一直发新版本。

另外，单机小游戏加新关卡、新场景，就是发一个新版本，没有别的办法同步，玩家更新后就能玩到。

  1. 认证和备案是一回事吗？

不是一回事，很多人搞混：

  • 微信认证：给微信交认证费，个人一年 30 元，开广告之前要做。交完以后会有第三方审核机构打电话来核实，平时不接陌生电话的，这几天要留意接听。
  • 备案：向管理部门登记，要做人脸核验，分小游戏和小程序两项。
  1. 一个人能注册几个？

个人主体能注册的小程序数量有上限，是 5 个，小游戏也算在里面。我自己的额度早就用完了。想做很多款游戏的话，这是要提前考虑的事。

  1. 广告收入算营收还是利润？

营收。到现在还没投流，成本只有每年 30 元认证费和 Claude Code 的订阅费，所以和利润差不多。

第二步：注册

邮箱不够用怎么办？

微信平台每注册一个公众号、小程序或小游戏，都要一个新邮箱。

我的办法是用自己的域名：

  1. 买一个域名，几十块一年，接到 Cloudflare；
  2. 在「电子邮件 → 电子邮件路由」里开启，加一个目标地址，比如你的 Gmail；
  3. 打开「全部转发」（Catch-all）。

之后发到「任何前缀@你的域名」的信，都会转到你的 Gmail。folkgame@、minigame@、douyin@……不用提前创建，想用哪个直接填。

前缀按平台起名，以后一看收件人就知道是哪个号的信；哪个地址开始收垃圾邮件，就知道是哪个平台泄露的。

评论区还补充了两个更简单的办法：Gmail 地址里加点或者加「+后缀」，也能当成不同的邮箱用；有域名的话，阿里企业邮箱免费给 50 个地址。

我 10 月发过的帖子：Grok Bot 的邮箱也支持「+后缀」别名，一个邮箱能当一堆用

第三步：做游戏

1.用什么引擎？

没用引擎。我的游戏是纯 Canvas 画的，原来是网页版，后来让 Claude Code 搬进微信。像素风格的游戏最适合新手，美术难度直接降一档。

  1. 用什么 AI？

我用 Claude Code。评论区有人用别的工具做了一晚上，说可玩性很差，打算放弃。

我的体会是：代码 AI 都能写出来，可玩性要你自己盯。我现在已经做到 380 关，每一关都要能说出它的「顿悟点」，说不出来的关就要重做。上一篇讲过我的关卡标准，这里不重复了。

还有一个小经验：我有一台 MacBook Air 和一台 Mac mini。渲染视频、跑测试这种费电脑的活，我让 Claude Code 通过 SSH 派给 Mac mini 去干。Mac mini 风扇一响，我就知道 Air 给它派活了。

  1. 关卡太难，玩家卡住怎么办？

有玩家问第 60 到 63 关怎么过。

难的关一般都有一个顿悟点，盒子的排布是固定的，一条路走不通，下次换一条。我的游戏也故意留了一个设计：觉得这局没戏了，随便点几下输掉，就能马上重来。

卡住的时候，正是玩家最愿意看激励视频的时候，第六步再讲。

  1. 排行榜怎么做？

排行榜能把一件很普通的事变得上头。前段时间微信那个「家乡话收集」小程序，本身没啥意思，但有排行榜，我硬是录了 1119 句，录到了我们地区第一。

所以我也给「蚂蚁搬画」加了排行榜。最爽的一点：好友榜和群排行不需要自己的服务器。

游戏用 wx.setUserCloudStorage 把「打到第几关」存到微信那边。好友的数据只能在「开放数据域」里用 getFriendCloudStorage 读，画在一块共享画布上，游戏本体拿不到好友数据，只能把那块画布贴到屏幕上。全服排行榜才需要自己的服务器，我没做。

上线前有四道门槛：

  1. 小程序备案要先过。没备案只能是「单机」，隐私指引锁死在「不处理任何用户信息」；
  2. 提审时网络类型从单机改成联网；
  3. 隐私保护指引里声明「微信朋友关系」；
  4. 后台打开「隐私授权弹窗」。第 4 步我漏了，真机报错。

两个小坑：好友名字的字段是 nickname，不是 nickName，写错了上线后榜上一排全是「好友」两个字；后台开关改完要过几分钟才在手机上生效，别急着怀疑代码。一定要真机测。

游戏里我放了这几处：主菜单顶部的好友榜；通关卡片上「再过 21 关追上某某」；失败卡片上「好友里 3 人过了这关」；「发到群里比一比」，群友点开卡片就能看到这个群的排名。

左：通关卡片上的「再过 21 关追上某某」；右：主菜单里的好友榜（开发者工具里的测试数据）

两条原则：分享没有任何奖励，微信本来也不让诱导分享；不同意授权也完全不影响玩。

  1. 数据后台怎么做？

我的游戏有网页版和微信小游戏两个版本，数据也是两套。

网页版：自己搭的后台。 数据发到我自己的服务器，用的是 Cloudflare Worker 加 D1 数据库，玩家不用登录，只用一个随机的匿名 ID。

每一局的每一次点击都记下来：点了哪一列、哪下点了没拿动、为什么没拿动、用了什么道具。再让电脑把输掉的局回放一遍，找出「从哪一步开始，后面怎么走都赢不了了」。大家都输在同一步，说明那里有个关键选择没人看出来，这一关就要改。

每一关我看这几个数：多少人玩、通关率、第一次通关平均试几次、在第几步输的，还有玩家点了却拿不动的次数。同一种点不动特别多，说明这条规则没讲清楚，要改说明卡。

小游戏：用微信的 We分析。 小游戏的联网请求只能发到备案过的域名，所以这边我用的是微信自带的 We分析。它可以自定义事件，先在后台把事件名和字段建好，代码里一行就能上报。我只建了 4 个事件：关卡、广告、救援、从哪进来，细节靠字段区分。留存、渠道、每个渠道带来多少广告收入，微信后台本来就有。

这里有一个我写完增补帖才发现的坑：We分析免费版每天只收 5,000 条上报，也没有漏斗分析。我的小游戏一天要报几十万条，绝大部分都被丢掉了，算出来的通关率不能用。专业版要付费，额度也有限。

我打算用抽样解决：只让一小部分玩家上报，按玩家固定抽，同一个人要么全报、要么全不报。通关率是比例，抽样一样准。

所以我更推荐先做一个网页版：不用注册、备案、审核，做好就能发出来给人玩；自己的数据库没有额度限制，每一局都能完整记下来；网页上再放一个小程序码，还能给小游戏引流。

两套埋点和后台的代码，全是 Claude Code 写的，我只说想看什么。上线第一天就埋点，没数据的那几天，以后补不回来。

  1. 背景音乐从哪来？

也是 Claude Code 做的。我用了 Felix Rieseberg 那篇《How to be more ambitious》里的提示词，让它自己设计、自己评估、自己改，前后大概花了三个小时。

Claude Code 把自己交上来的一版配乐退回返工：偏忧伤、太小声、挤占了顶栏，还列了这次要达到的标准

第四步：备案和提审

备案表单太长、截图太烦怎么办？

小游戏备案要填的内容又多又烦，可以直接让 Claude Code 操作浏览器去填。它会根据你的游戏代码和备案要求，自己生成内容、完成填写并提交。我下完命令就去干别的了。

截图也让它自己截：Claude Code 可以直接操作微信开发者工具。我第一次是自己填、自己截的，折磨了好久。

注意一点：微信公众号平台不允许 AI 操作页面，小程序平台可以。

第五步：开通流量主

上一篇讲过，开通条件有三种，满足任意一种就行：

流量主后台的开通条件

这一周我的体会是：游戏圈这条路，比攒 100 个独立访客更好走。

建议开发的时候就把游戏圈带上，先发满 5 篇官方帖子。你还在攒 100 个访客的时候，游戏圈这条大概率已经先达成了。

评论区还有人补充了一个细节，我很认同：游戏圈的入口要加到游戏代码里，让玩家从游戏里的按钮进，不要指望玩家自己去右上角「···」里找。

我的主菜单顶部：每日一关、游戏圈、好友榜，玩家点一下就能进游戏圈

第六步：广告

多少人玩，能赚多少？

被问得最多的就是这个，直接给数：

  • 平时每天活跃玩家六千左右，一天收入两千左右；
  • 收入最高的 3016 元那天，活跃玩家大概九千；
  • 平均下来，一个玩家一天大概能赚 3 毛。

我以前对游戏也不了解，没想到 6000 个人一天能赚 2000 块。

钱主要从哪来？

主要是激励视频，上一篇讲过，占九成左右。插屏收入很少，我基本当它没用。

流量主后台，11 月 16 日（收入最高的那天）：激励广告 2818.59 元，插屏只有 21.84 元

卡死时的失败页：带 ▶ 的按钮都是激励视频，玩家自己选

插屏的一个小细节

有时候玩家一边玩游戏一边干别的，游戏就挂在那里忘了。

所以我加了一个设定：游戏停在当前界面、超过两分钟没有任何操作，就弹一个插屏。这时候玩家不在玩，不会觉得被打扰，不放白不放。

第七步：流量

1.投流了吗？

还没投。一开始我算过，买一个新用户要一块钱左右，一个玩家一天只赚三毛，还会流失，觉得回不了本。后来按后台数据重新算了一遍，如果只买益智类的核心玩家，有可能回本。我准备拿一小笔钱试一下，有结果了再跟大家说。

  1. 新游种子什么时候开？

新游种子是微信给新游戏的一次推荐机会，只有一次。我的建议是：先开通广告，再把留存打磨好，最后再开。有了广告，推荐来的人才能变成收入；留存好了，推荐带来的人才留得住。

至于游戏要不要打磨好再上架：我是一边上架一边打磨的。

  1. 收入为什么会回落？

从截图能看出来，11 月 16 日是高点，之后每天回到了一千九左右。这背后是一笔很简单的账：

  • 收入 ≈ 活跃玩家 × 每人收入。每人一天 3 毛左右，基本是稳的，所以收入跟着活跃玩家走；
  • 活跃玩家 = 留下的老玩家 + 新来的玩家。我现在活跃玩家的日留存在 46% 左右，也就是说，每天都有一半多的人要靠新玩家补上；
  • 新玩家主要来自平台推荐。推荐量一回落，补进来的人少了，活跃玩家就跟着回落。

所以要让收入稳住，办法只有两个：让更多人留下来，或者找到更多新玩家。

评论区有人建议做长线的东西，比如把打完的画做成收集图鉴，再用收集解锁头像、称号。我觉得很有道理，正在让 AI 做。

最后

这一周最开心的，除了收入，是看到很多人照着那七步动手了：有人两天做完第一版在等审核，有人上线两天赚了 19 块，有人把小游戏和家里的农家乐结合起来引流。我发了一条帖子，让大家把自己做的小游戏贴在评论区，一下子收到了几十个：挖掘机拆房子、种地、坦克大战、倒水和茶文化……都挺好玩。

用户画像里九成以上是女生，所以我下一步打算多往小红书发一发。

在微信里搜「蚂蚁搬画」就能玩，上面说的排行榜、游戏圈、救法都能在游戏里看到。

也可以用微信扫一扫下面这张图，直接打开。

没有微信的话，浏览器打开 https://ants.pomodiary.com 也能玩网页版。

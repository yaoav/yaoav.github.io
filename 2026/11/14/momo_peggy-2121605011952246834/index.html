抖音200W粉丝博主AI美女涨粉技术保姆级教程

兄弟们，247.3 万粉丝，3617.1 万获赞，157 条作品。

这是这次拿到的“温柚柚”主页截图里显示的数据。

往下看，作品封面里的元素很集中：人物、服装、表情，加上相近的拍摄距离和背景。

换一套衣服，换一个角度，再换几个小动作，就能围绕同一个人物继续做内容。

数据以这张截图为准。原账号的制作方式未知，本文用自己的 AI 角色练习同类视频的镜头和动作。

猫哥直接给大家拆解这类账号视频到底怎么做。

拿这次约 6 秒的参考片来说，画面主要围绕一个人展开。

开头镜头有变化，停稳以后，靠视线、眨眼、偏头这些小动作继续推进。想复刻这种感觉，就要把动作的顺序和幅度写出来。

只丢一句“帮我生成一个美女自拍视频”，能控制的信息太少。

所以，这次我把它放进 YouArt Desktop 桌面应用，按下面这条流程来做：

反推视频 → 整理首帧和动作提示词 → 做自己的角色三视图 → 替换人物 → 调用爆款克隆 Skill。

我之前写 Codex 和 Skill 的时候，经常讲：把输入、步骤和判断标准留好，下一次才能复用。这次的人物视频，也可以这样处理。

下面把操作顺序、截图和提示词一起放出来。有需要的兄弟，拿自己的参考视频跟着做就行。

第一步，打开 YouArt Desktop，先让 Agent 教你怎么问。

先从 YouArt 下载页 安装桌面应用。本文展示的操作都在 YouArt Desktop 里进行。

打开对话，在模型选择处选 Fable 5.2。

先不用研究摄影术语，直接把自己的需求说出来。我发的是这样的意思：

我需要你帮我分析一个视频内容，然后看一下它是怎么拍摄的，分析这个视频的所有信息。
我不知道怎么描述分析要求，你可以告诉我一个指令，怎么去解析这个视频吗？

这一步很适合刚开始做视频的人。

你可能知道这个画面好看，却说不清是景别、光线还是运镜起作用。先让 Agent 把分析框架列出来，后面就有东西可以逐项检查。

这一步已经得到一份十项拆解指令，后续可以反复拿来分析不同视频。

第二步，复制拆解指令，和视频一起发过去。

把参考视频添加到输入框，再粘贴下面这段话。

输入框里同时放视频和文字，让分析围绕具体素材展开。

这份回答里，我会重点看动作和镜头的关系。

比如，人物什么时候看向镜头，镜头在她抬头之前还是之后停稳，偏头时肩膀有没有跟着动。这些细节写清楚，后面生成视频才有明确要求。

反推到这里，还应该多问一句：

请重点分析视频开头的吸引点、后续的动作变化和结尾状态。
把人物动作、镜头运动分开描述，并为每个镜头或动作段落整理可直接使用的 AI 视频提示词。

前面参考的视频拆解教程和人物与动作工作流教程，可以帮助我们把分析维度、人物准备和动作处理分开。落到自己的案例上，每条要求都要跟着实际视频走。

第三步，要两份提示词，先把初版人物场景图做出来。

接着在同一个对话里发：

请根据刚才的视频拆解，分别给我首帧图提示词和视频提示词。
首帧图提示词：写清人物外观、服装、姿态、构图、背景和光线，输出 9:16 竖版的人物场景图方案。
视频提示词：写清动作先后顺序、表情变化、镜头运动和各阶段时长。这次先整理一版约 6 秒的方案。
请说明你选择的参考画面，是视频真正的开头，还是镜头停稳后的画面。

可以看到，这版画面用了深色背景、米色服装、侧辫和自拍构图。人物、衣服与背景放在一起，后面替换角色时就有了具体的画面参照。

这里有个容易忽略的地方。

这次 Agent 选的是“镜头甩上来、停稳之后”的画面，用它固定人物、服装和场景。

如果把这张稳定人像直接作为视频起始画面，生成的视频就会从这个构图开始。想保留原片开头的甩镜头，还要在视频方案里单独处理这段运动。

我会先把稳定状态的人物做好，再去调整开场动作。脸、衣服和背景还没确定，就同时加上大幅运镜，很难看出问题究竟出在哪一步。

第四步，做自己的 AI 角色，把正面、侧面、背面一次定下来。

初版人物图有了，接下来就换成自己的角色。

做系列内容时，我会先留一张角色三视图。同一人物的正面、侧面和背面放在一起，脸型、发型、身体比例，以及服装的前后结构，都能对照检查。

这次画布里的三视图，是盘发、白灰运动休闲服装、赤脚的角色。它可以作为新人物的参考；最终视频是否沿用这套衣服，要在后面的替换要求里单独说明。

下面这版提示词，在通用模板上补充了参考图分工，也把不同视角下的光影要求写得更具体。把花括号里的内容换成自己的设定就能用。

角色描述尽量具体。比如“24 岁的原创成年女性角色，柔和鹅蛋脸，自然眉眼，身形匀称，日常穿搭博主气质”，会比“超级好看的网红美女”多出许多可检查的细节。

这里还要分清两个画幅：三视图用 16:9 横版，方便把三个全身视角排开；人物场景图和这次的视频用 9:16 竖版。

三视图生成后，先看正面和侧面能不能认出同一个人，再看发型、服装前后结构和手脚。选定的角色图保存下来，后续制作继续引用。

第五步，把新角色放回场景，明确哪些地方要保留。

接下来就是截图里的两张图引用。

第一张是已经确定构图、衣服和背景的人物场景图；第二张是自己的新角色参考。

如果直接写“把第一张的人物替换成第二张”，对脸、头发、衣服和姿势的要求还不够明确。

这次后面的指令收窄成了：

将这张图 @Image1 的人脸替换为第二张 @Image2 的人物，其他服饰不变。

需要控制得更细，可以复制这一版：

请以 @Image1 为基础，使用 @Image2 中我已经确认的新角色，替换 @Image1 人物的面部五官和脸型。

@Image1 决定：构图、身体姿势、视线方向、原有发型、服装、背景和光线。
@Image2 决定：新角色的面部五官与脸型。

保持自然的头颈衔接，肤色和受光一致，头部比例与原有姿势匹配。
不要把 @Image2 的白底、站姿或另一套服装带进场景。
输出一张 9:16、真实摄影质感的人物场景图。

注意，提示词里的 @Image1、@Image2，要对应到你实际添加的图片引用。检查缩略图，别把场景图和角色图的位置弄反了。

前面截图出现了 Seedream 5.5，这张截图出现了 GPT Image 2，它们在这里是图像编辑区的模型选项。左侧 Fable 5.2 负责这次对话中的分析与任务沟通，几个名字各有各的位置。

选好替换后的人物场景图，再往下走。后面的人物脸型、衣服和背景，都以这张确认过的画面为参照。

第六步，调用爆款克隆 Skill，把角色参考和视频接起来。

在对话输入框里选中这个 Skill，再添加素材与替换要求：

/viral-video-clone

然后引用参考视频和自己的角色素材，描述替换要求。

下面这张截图里，可以看到输入框已经带上了这个 Skill，人物素材以 Media 引用，视频也通过素材标签引用。右侧画布下方就是前面准备的角色三视图。

截图展示的是素材引用和待发送的任务设置，最终效果还需要查看完整输出视频。

为了把第五步已经确认的画面也带进去，我建议再附上那张人物场景图，把三份素材的用途写完整：

检查素材引用无误后，发送任务。

这样，参考视频负责“怎么动”，确认后的人物图负责“长什么样、穿什么、在哪里”。

如果你想把新角色三视图里的整套造型都用进去，也可以把要求改成“发型和服装采用角色三视图”，并先更新人物场景图。几份素材的要求对齐以后，再做视频。

第七步，打开完整视频，检查动作里有没有变样。

生成一张好看的图之后，还得看看她动起来是什么样。

我会先正常速度看一遍，再停在抬头、眨眼、偏头这些位置检查：脸型有没有变化，五官有没有突然移动，肩颈连接是否自然，衣服和背景有没有一起扭动。

发现问题，就直接说出时间和现象。

比如，可以这样反馈；

时间点和问题要替换成你自己成片里实际出现的情况：

请修改这版视频的 2—3 秒：人物偏头时脸型发生了变化。
请参照已确认的人物场景图，保持面部身份稳定，并减小这一段偏头幅度。
其余已经满意的构图、服装、光线和动作顺序保持不变。

一次先处理一个主要问题，再和上一版对照。
每轮都同时换脸、换衣服、换动作，最后很难知道哪个修改有效。

算成本也一样。角色重抽、图片修改、视频失败重跑，都应该记进去。单次按钮旁边显示的数字，算不出整个流程的总成本。

先把一条短样片调顺，再考虑增加数量。

复刻

再聊聊大家关心的变现。

广告分成、伙伴计划、品牌广告、网盘拉新、合集、服装带货、教学服务，都可以围绕自己的内容方向研究，但每一种都需要不同的承接方式。

**平台收益，**先看自己的账号能开通哪些计划、准备发布的作品是否符合条件。本文这条短样片，还没有可以拿来展示的发布收益记录。

**服装带货，**可以把角色和穿搭系列结合起来，但衣服款式、商品细节得对得上。生成图里的面料表现，要跟真实商品素材核对，不能当成实拍效果。

网盘拉新和资料合集，可以围绕自己整理的角色设定、提示词、制作记录和原创教程来做。别人愿意保存的，往往是拿回去能用的东西。

教学服务也一样。能把“为什么变脸、为什么换错衣服、怎么修改动作”讲清楚，才有具体的交付内容。

卖号这条我不列入操作路线。抖音用户协议对个人账号转让、售卖有限制，把自己的作品、角色和制作能力留下来，更适合持续积累。

对于一直在研究 Skill 和 AI 视频工作流的人，这个过程还能留下另一份资产：一套自己用得顺的制作方法。

同一个角色，下一条可以换服装，再下一条可以换场景。已有的人物参考、拆解指令和修改记录，都可以继续用。

这次 YouArt Desktop 的工作区，左边保留分析对话，右边集中放人物图、角色卡和视频素材。

做下一轮时，可以直接对照已有材料，明确告诉 Agent 要改哪里。

有需要的兄弟，先拿一条短视频试试。

从拆解开始，定一个自己的角色，把第一条样片做完整。

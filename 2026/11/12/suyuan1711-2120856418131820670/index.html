一、封号原理：平台到底看什么封号

1.1 官方封号的三条红线与唯一判断标准

踩了三十多个号的坑下来，我觉得网上大多数防封教程都把这件事搞得太玄学了。

其实 Anthropic 在用户条款里写得明明白白，决定封不封你就三条红线：

第一，你是不是来自它不支持的地区（中国大陆、香港、澳门都不支持）。

第二，你有没有拿账号搞蒸馏、高并发刷量，或者把个人订阅反代成 API 接进不该接的中转池。

第三，你有没有聊违规内容。

很多人以为 Anthropic 是「禁止中国人用」，这完全是误解。

最直接的铁证是：我群里好几位读者在触发 KYC 实名认证后，直接拿咱们中国的护照上传，很顺利就通过了审核。

官方从来不禁止中国人用，它防的只是「人在不支持的地区」以及「批量滥用的机器行为」。

所以后面所有步骤，其实都围绕着同一把尺子：

「一个在美国（或新加坡、日本、韩国等支持地区）工作生活的中国人，会这么做吗？」

拿这把尺子一量，正反两类行为一眼就能看穿：

1.2 决定账号生死的两个核心权重

真正决定一个号命硬不硬的，一是它**「出生那一刻（注册和头几天）」的初始权重干不干净**，二是你日常用的时候网络有没有偷偷漏出国内 IP。

你想想，一个真正的美国用户来中国出差旅游，在酒店连了一次国内 Wi-Fi，Anthropic 还不至于一棒子把他打死；但如果你这个号在注册出生那一刻用的就是万人骑的脏 IP，

或者刚出生第二天就在美国和国内 IP 之间反复横跳，平台直接就会给你打上「高危灰产号」的底子，后面充钱不是弹 KYC 就是秒封。

所以接下来的第 2 到第 8 章，咱们就围绕**「把新号出生权重养到最干净」和「日常网络哪怕闪退也绝不漏国内 IP」**这两件事，一步步把环境搭稳。

二、准备节点：什么样的海外 IP 才不会被秒封

注意，我从来没说过「一定要买昂贵的真住宅 IP」，重点不是住宅还是机房，而是我们需要一个没人滥用过的「干净出口」，按你手头情况二选一就行：

三、网络防漏：为什么开着魔法网络还是会暴露国内 IP

3.1 开着代理依然漏国内 IP 的三个常见原因

很多人平时开着科学上网软件用得好好的突然被封，最常见的原因就三个：

**第一，只给 claude.ai 和 anthropic.com 配了代理规则。**但 Claude 客户端遥测和错误报告会调第三方服务（如 Datadog 等），那些域名不在你的代理规则里，直接走了国内直连，一眼暴露你在国内。

**第二，没开虚拟网卡模式（TUN），或者代理软件半路闪断。**终端命令行默认不吃系统 HTTP 代理；而且一旦海外节点掉线或 Clash 崩溃退出，流量自动回落成本地直连（DIRECT），直接拿中国 IP 连了上去。

**第三，让登着号的 Claude Code 自己去改 Clash 网络配置或连国内设备！**上个月评论区至少有十五六个人栽在这：让正在运行的 Claude Code 改分流规则，结果代理重启闪断了一秒，当场用国内真实 IP 发出请求，当晚号就无了；

为什么这套「国内白名单以外全走海外」的分流逻辑是绝对稳的呢？

所以在这一屏里，务必按下面这套实测最稳的参数来配：

**硬件噪音开关：**只打开「媒体设备（噪音 Auto）」，把 Canvas、WebGL 图像、AudioContext、ClientRects、SpeechVoices 的噪音开关全部关掉（设为真实）！

硬件底层参数：下面的 WebGL 元数据、WebGPU、CPU、RAM、设备名称、MAC 地址，全部选「真实」；Do Not Track 选「默认」。

配合上面关掉假噪音，待会儿跑 BrowserScan 检测就能拿到 100% 浏览器指纹真实度。

4.1.4 第四步：滑到底部「高级设置」，开启端口扫描保护并锁死固定指纹

七、清理电脑：封过号的电脑怎么避免新号连坐

7.1 为什么换了新号还会被连坐？

账号和订阅都搞定了，在打开本机终端接上 Claude Code 干活之前，如果这台电脑以前登过其他 Claude 账号（尤其是之前封过号），一定一定要先把本机的旧残留清干净。

评论区经常有人问：「我这台电脑之前封过号，Anthropic 会不会记住了我的硬件指纹？要不要换电脑？」

今年早些时候我看过 Claude Code 的相关代码实现，直接说结论：它根本不读你的主板序列号，也不读网卡 MAC 地址。

它所谓的「设备 ID」，只是第一次启动时在本机配置文件里随机生成的一串字符，外加留在本地目录和钥匙串里的登录残留。

每次你用 Claude Code 发消息，请求里主要就带三个身份信号上去：账号 ID、本机随机生成的设备 ID、以及当前的会话 ID（Session ID），服务端就是把这三个信号组合起来做关联分析的。

看懂这个机制，你就明白为什么好多人换了新号还是被秒封了。

至于大家常问的「桌面客户端和 VS Code 插件能不能用？」，只要把本机残留清干净、加上前面第三章已经配好的虚拟网卡防漏，桌面客户端、VS Code 插件和 CLI 命令行的安全性完全一样，习惯用哪个就用哪个。

记住，这两步的顺序不要搞反了：必须先去 Anthropic 申诉，彻底救不回来了，最后再去苹果/谷歌退钱！

9.1 第一步：在原 AdsPower 环境里向 Anthropic 官方写申诉信

写英文申诉信时核心就抓准两点：一是说明自己一直是正常写代码和处理日常工作，没有任何违规或逆向蒸馏行为；二是重点写自己原本是 OpenAI Codex 的长期付费用户，专门为了刚发布的 Fable 5.2 和 Opus 付费转过来，结果刚付完钱正常用着就被误封了，实在太冤枉、太寒心了（这招最管用，下面模板里已经帮你写好了，别人小册里不会教这个）。

**第一，必须在注册那个号的 AdsPower 环境窗口里操作：**点申诉链接（封号提示页或邮件里的 Appeal 表单）和发邮件，都要让官方后台看到你申诉时的 IP 依然是那个稳定的海外 IP，千万别用国内网络裸连去填表。

**第二，问题分类选「其他（Other）」：**表单里如果让你选问题分类，直接选「其他（Other）」或者账号申诉就行。

**第三，删掉 AI 公文套话，带点真实用户的委屈：**让 AI 写完英文申诉信后，把里面太工整、太像公文的套话删掉两句，改得口语化一点（评论区有位读者就是把 ChatGPT 写的长文删掉了 AI 味，只留了几句大实话，第二天就解封了）。

9.2 第二步：申诉无望后，找苹果申请退回当月订阅费

为什么要等申诉明确被拒、确定救不回来了，再去苹果申请退款？

因为一旦你向苹果发起退款：第一，Claude 那边哪怕原本能解封也会彻底锁死；第二，向苹果退大额订阅费，有很大概率会被苹果顺手把这个美区 Apple ID 也封掉（而且苹果一般只有新号第一次申请通过率较高，三个月内很难退第二次）。

如果等了几天 Anthropic 明确拒了申诉，咱们走苹果内购的优势就体现出来了（网页绑卡被封现在是一分不退的）：

9.2.1 第一阶段：先在网页端自助申请退款（reportaproblem.apple.com）

苹果美区服务条款里虽然写着「所有交易均为最终交易」，但专门留了自助退款入口。虽然苹果审核没法保证 100% 必退，但全新美区 Apple ID 第一次申请退款，机器审核通过率其实很高，有很大概率能直接把当月的 20 刀、125 刀或 250 刀订阅费原路退回礼品卡余额。

具体按下面四步走（对应下图红圈 ①～④）：

**第一步，打开苹果问题报告页并登录：**在 AdsPower 指纹浏览器里打开苹果官方退款页面 https://reportaproblem.apple.com ，登录你买订阅用的那个美区 Apple ID。

**第二步，选申请退款与理由：**点击第一个下拉框 I’d like to… 选择 Request a refund（申请退款）；接着在第二个下拉框 Tell us more… 里选择 I didn’t mean to buy this（不小心误购）或 App didn’t work as expected（应用无法正常使用），然后点右侧蓝色的 Next。

**第三步，勾选当月刚扣款的 Claude 订阅提交：**在下面的订单列表里勾上当月刚扣款的 Claude 订阅（20 / 125 / 249.99 美元），点击提交。提交后等 24 到 48 小时看审核结果，通过后钱会自动退回你的苹果礼品卡余额。

9.2.2 第二阶段：若网页机器审核被拒，找苹果人工客服二次复议

万一你在 https://reportaproblem.apple.com 网页上提交后被系统机器自动审核拒了（显示 Not eligible for a refund），也别轻易放弃！

直接照着第六章找苹果在线客服的路子，去 https://getsupport.apple.com 找人工客服聊，跟人工客服说明软件刚付完大额订阅费就被锁死、完全无法使用，请他人工帮你升级处理退款（Escalate for a manual refund），又能多救回来一次机会：

**第一步，进入苹果人工在线客服（对应下图红圈 ①～⑤）：**在 AdsPower 指纹浏览器里打开 https://getsupport.apple.com ，依次点击 ① App Store -> ② Subscriptions & Purchases（左上角，别点右边礼品卡） -> ③ 右侧选择 Request a refund（或 Check refund status） -> ④ 滑到底部点左下角 Get more help -> ⑤ 点击 Live Chat 进入在线人工文字聊天。

**第二步，生成 Support PIN 临时验证码：**另开一个标签页打开 https://account.apple.com 登录你的美区 Apple ID，滑到页面最底部点 Support PIN 生成一个临时验证码备用。

9.3 重开新号，哪三样必须换、哪一样不用换？

最后把大家最常问的收尾问题说透：如果旧号申诉没过、退完款准备重开新号，到底要不要换 IP、换苹果号、清电脑？

答案是：被封后重开，本质上就是把自己当成一个「从未用过 Claude 的新用户」重走一遍流程，除了原本干净的静态 IP 可以不换，其余跟旧号绑定的身份痕迹必须全部换新：

第一，电脑残留与设备 ID 必须清：让 Codex 跑一遍第七章的 claude-cleanup 重置本机设备 ID、清掉旧登录态；而且新号登上去后绝对不要敲 claude –resume 恢复旧会话，直接开全新会话接着干。

**第二，AdsPower 环境窗口与邮箱必须换新：**在 AdsPower 指纹浏览器里删掉旧窗口，重新建一个全新的指纹窗口，换一个全新的 Proton 邮箱去注册。

**第三，美区 Apple ID 必须换新：**旧号绑过的那个美区 Apple ID 已经被关联标记了，继续拿它订新号必被连坐，重开新号必须换一个全新的美区 Apple ID。

**第四，原本干净的独享静态 IP（或自建 VPS）可以不换：**只要你复盘下来，这次被封是因为「忘开魔法网络漏了国内 IP」「接了反代」或者「跑了高危动作」，而不是因为贪便宜买了三四十块的万人骑脏 IP（注册时没弹手机号验证或 on hold）；

那你手里这颗 70 块以上的干净静态 IP 根本没被拉黑，重开新号继续用它就行，不用白花冤枉钱重买。

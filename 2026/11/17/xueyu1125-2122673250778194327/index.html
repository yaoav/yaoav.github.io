万字干货｜Gemini 4 + Antigravity，从 0 到 1 跑通全自动出片（附 Agent 指令）

很多人不知道：Antigravity 其实不能生成视频。

上一篇我写它能把爆款视频的提示词反推出来，文末吐槽了一句：谷歌全家桶，就差出片这最后一块。

这两天我把这块接上了。

现在同一个对话里，它看完参考视频、画好角色定妆照、写完提示词，直接调视频模型出片，再下载、配回原声、抽帧给我验收。我只管花钱前点头和最后看片。

一共跑通三条路，前两条用的全是 Google AI 会员本来就送的额度。 Pro、Ultra 5x、Ultra 20x 都能用。

我自己是 Pro 会员，下文的额度和账单都按 Pro 实测；Ultra 的额度更多，方法完全一样。

每节末尾都有一段指令，复制给 Antigravity 就能跑。

一、Antigravity 缺的那一块：看得懂，出不了片

先交代前情。上一篇讲的是：刷到一条爆款视频，作者不给提示词，就丢给 Antigravity 让它看，它能把镜头、运镜、节奏反推成提示词。

能反推，是因为 Antigravity 的大脑是 Gemini。GPT、Claude 看视频是抽帧看截图，Gemini 是真的看懂了动作和节奏。 现在换成 Gemini 4，看片这一步更稳。

但那篇写完我很别扭：前面看片、反推、画定妆照，它全能干；一到出片，我还得自己打开网页、传图、点生成、等、下载，再丢回给它检查。

最麻烦的不是点几下鼠标，是闭环断了。

它看不到成片，就没法对着原片挑错、改提示词、再跑一版。来回搬运一次，我就得在场一次。

接上以后，分工变成这样：

  • 我：说清要做什么片子，花钱前点头，看样片，拍板。
  • Antigravity：看原片、定角色、写提示词、选通道、提交、下载、配回原声、抽帧和原片并排对比，不合格自己改一版再交。

这篇讲的就是”出片”这一块，怎么接。

───

二、你的会员里，藏着两份出片额度

很多人订了 Google AI Pro 或 Ultra，只拿来在网页上聊天。其实会员里有两份能出视频的额度，跟 Antigravity 一拍即合。

第一份：Gemini API 赠金（美元）。

今年起，Google 把开发者计划的福利并进了 AI 会员，每个月送一笔 Google Cloud 赠金，可以拿来调 Gemini API，包括视频模型。按 Google 开发者计划的官方 FAQ：

  • Pro：每月 10 美元
  • Ultra 5x：每月 40 美元
  • Ultra 20x：每月 100 美元

赠金要自己去领，领了才有；每笔有效期一年。第三节有图文步骤。

第二份：Google Flow 点数。

Google Flow 是谷歌官方的 AI 视频创作网页（flow.google.com）。你可以把它理解成谷歌版的即梦：传图、传视频、写一句话，它帮你出视频。

会员每个月送 Flow 点数，Pro 是 1000 点，Ultra 多得多。出视频按点数扣，生图基本不扣。

顺手把几个会反复出现的名字讲清楚：

  • Omni、Veo：谷歌的两个视频模型系列。Omni 擅长”看着参考视频和参考图来生成”，这篇主要用它（Omni 1.2 Flash）；Veo 偏电影感画质。
  • Nano Banana 2（Flow 里简称 Nano 2）：谷歌的生图模型，就是网上很火那个”香蕉”。在 Flow 里用它画角色图，实测不扣点数。
  • Antigravity：谷歌官方的命令行 AI Agent，大脑是 Gemini。能读文件、跑命令、开浏览器，这篇里它是总导演。

三条路，一句话说清区别：

  • Gemini API：吃赠金，纯后台跑，最省心；参考视频最长 10 秒。
  • Google Flow：吃点数，能直接喂 15 秒参考视频；但它没有接口，得让 Agent 操作网页，审核也严。
  • 外部视频命令行：吃第三方平台的积分；谷歌这两条卡住时兜底，长镜头、多人复杂场面更稳。

───

三、第一条路 · Gemini API：用会员赠金后台直出

原理：Agent 直接给谷歌的视频模型发请求

API 就是程序之间的”窗口”。Antigravity 把”参考视频 + 角色图 + 提示词”打包发给谷歌的视频模型，模型在云端生成，Antigravity 每隔一会儿去问一次好了没，好了就下载。

全程不开网页、不占你的屏幕。 这是三条路里最像”全自动”的一条。

实操第 1 步：把会员赠金领出来

打开 Google AI Studio（aistudio.google.com），左下角有「领取免费 API 赠金」的卡片，点进去。

会直接弹出领取窗口，选好结算账号，点「兑换并继续」。Ultra 会员这里显示的金额更高。

领完以后，在 Google Cloud 的「结算 → 赠金」页能看到一行 Google Developer Program premium benefit、状态「可用」，就是领到了。

实操第 2 步：先预充 5 美元，赠金才用得上

我领完赠金去调接口，AI Studio 结算页弹了一条黄色提示：此账号已转为预付款结算方式，余额需大于 0 美元方可恢复服务，符合条件的 GCP 赠金会优先抵扣。

这一步很多人会卡住： 赠金领到了，接口还是调不通。我是先预充了最低的 5 美元，服务才恢复。充完以后，调用费用会优先从赠金里扣。

实操第 3 步：拿 API 密钥，交给 Antigravity

在 AI Studio 左侧「API 密钥」里新建一把密钥，选你刚绑定赠金的那个项目。

密钥别直接贴进对话里。 存成本机的一个文件（比如 ~/.config/video-gen/.env，权限设成只有自己能读），然后告诉 Antigravity 文件在哪。

使用边界：这 4 条踩过才知道

① 参考视频最长 10 秒。

模型能输出 15 秒，但你喂给它当参考的原视频，超过 10 秒直接被退回。

想复刻 15 秒的片子，就切成两段（比如 0-8 秒、7-15 秒）分别跑，再拼起来。拼接处人物衣服、站位可能对不上，后面 Tips 里说怎么防。

② 参考视频要先去掉声音。

带音轨的视频传上去，秒拒，连原因都不细说。先把声音去掉再传，出片以后再把原视频的音乐配回去。这两步 Antigravity 用 ffmpeg 一句命令就能做。

③ 参考视频不能比你要的成片短。

你要 8 秒成片，参考视频就得 ≥ 8 秒，哪怕短 0.5 秒也会被拒。剪的时候多留 0.1-0.2 秒最稳。

④ 不说分辨率，它默认给你 720p，很贵。

我第一次没注意，两条 9.5 秒的 720p 直接花掉 3.16 美元，一条 1.58。Pro 一个月才 10 美元。

先用 360p 试，构图、动作都对了再出高清。

Tips：提示词怎么写，换角色才不乱

  • 按衣服认人，别按位置认人。 多人舞台一换位，”左一换成 A、左二换成 B”必乱。要写”穿黑袖白衬衣的那位换成 A”，模型会跟着衣服追。
  • 告诉它角色图只管长相。 角色定妆照一般是站着摆拍，不说清楚，成片里人物会照着定妆照的姿势站桩。加一句”角色图只锁长相和服装，动作完全照原片”。
  • 背景要锁死。 不写的话，模型会把定妆照里的背景搬进来。写清”保留原片的舞台、灯光和机位，只换台上的人”。
  • 提示词短一点反而好。 我堆过一大串”必须、严禁”，结果请求直接校验失败；删到简洁清楚，一次过，动作还更自然。
  • 出片后要抽帧对比。 让 Antigravity 从原片和成片各抽 6 帧拼成一张图并排看，比你自己拖进度条快得多。

四、第二条路 · Google Flow：用深度灰模过审，花会员点数

原理：Flow 能干活，但它没有门

Flow 有三个 API 没有的好处：

  • 能直接喂 15 秒参考视频，不用切段；
  • 扣的是会员点数，不花赠金；
  • 出片后下载时可以 5 点升到 1080p，比重新生成高清便宜得多。

在 Flow 里，Omni 1.2 Flash 出一条 15 秒：360p 是 20 点，720p 是 60 点。下面这张是我开着 720p、一次出 2 条时的报价。

问题是：Flow 是给人用的网页，没有给程序用的接口。 Agent 想用它，只能像人一样去操作网页。这里有三道坎：

  • 没有官方接口，只能模拟浏览器操作；
  • 有人机验证，谷歌会拦”一看就是机器”的无头浏览器，必须是真的 Chrome 窗口；
  • 上传文件走的是系统原生的选文件窗口，脚本点不进去，本地视频传不上去。

两种接法，各有千秋

接法一：开源工具 gflow-cli。

有人把 Flow 网页背后的接口包成了命令行，还自带 MCP（让 Agent 直接调用的插件接口）：

https://github.com/ffroliva/gflow-cli

  • 好处：一句命令就能生图、生视频、查点数，几乎不费 Agent 的算力；
  • 不足：只能传图片，不能传参考视频；默认只下载 360p；每次会弹出一个独立的 Chrome 窗口抢你屏幕（我写了个小脚本让它自动最小化）；
  • 风险：它是非官方的，调的是谷歌的内部接口，谷歌随时可能改，账号风险自担。

接法二：web-access 这类浏览器 skill。

让 Antigravity 直接接管你日常那个已登录 Google 的 Chrome，像人一样点按钮。

  • 好处：网页上能点的它都能点，挂视频、切分辨率、点 720p 下载都行；
  • 不足：每一步都要看页面、截图、判断，非常费算力，也慢；参考视频第一次进项目，还是要你手动拖一下（就是上面说的那个系统选文件窗口）。

我的组合： 生图、注入角色图、查点数这种轻活交给 gflow；挂参考视频、提交、下载 720p 这几步交给浏览器 skill。你只需要在开头拖一次视频。

最大的坎：真人视频过不了审

我第一次直接把女团的打歌原片拖进去，进度跑到 83%，卡片直接消失了。另一条连卡片都没出。没报错，也没扣点。

Flow 对真人脸和有版权的画面审核很严，会在后台静默取消。

解法是深度灰模。

深度灰模（行业里叫深度图，Depth Map）就是把彩色视频洗成”离镜头近的发白、远的发黑”的灰色剪影：五官、衣服花纹、台标全没了，只剩人在哪、怎么动、镜头怎么推拉。

审核看不到真人和版权内容，就放行了；模型照样能读出站位和运镜。我两条 15 秒都是一次出片。

实操步骤

① 本地把原片转成深度灰模。

让 Antigravity 用开源的 Depth-Anything-V2 模型转。本地跑不用钱，就是慢：15 秒 720p 的视频，我这台老 Mac 用 CPU 跑了 20 分钟左右。

② 在 Flow 里新建项目，把灰模视频拖进去。

这是全流程唯一要你动手的一步。

③ 让 Agent 把角色图注入同一个项目。

用 gflow 调 Nano Banana 2，把角色定妆照传进同一个项目。第一次传图，Flow 会弹一个”确认你有权使用这张图”的窗口，你在网页上点一次确认就行。

④ 让 Agent 挂素材、提交。

点输入框左边的「+」，先切到「视频」标签挂灰模，再切「图片」标签勾角色图，写提示词，提交。

⑤ 出片后下载，配回原声。

满意的那条，下载时选 1080p，多花 5 点。

使用边界

  • 深度灰模丢掉了表情和手指这些细节。 适合”同构图、同节奏”的二创；要逐帧 1:1 复刻舞蹈，不如第一条路。
  • 只能放在会员点数够的时候用。 点数用完，这条路就停了，下个月再来。
  • gflow 是非官方工具。 谷歌改版它就可能失灵，别把它当唯一的路。

Tips：省点数、少翻车

  • 提交前看一眼底部是不是”15 秒”。 「+」弹窗默认停在”全部/最近”，新生成的图片会把视频顶下去。我就因为这个，一次本该挂视频的任务按 8 秒纯图提交了，白扣了点数。
  • 别同时挂”多人合成的同框图”。 猫那条我多挂了一张正面合成图，结果镜头全程正面单机位，原片的切镜没了。只挂灰模 + 单人角色图。
  • 先 360p 试动作。 20 点一条，动作对了再出 720p，或者直接下载时升 1080p。
  • 生图尽量放在 Flow 里做。 Nano Banana 2 生图实测不扣点。

一键甩给 Antigravity

───

五、第三条路 · 外部视频命令行：LibTV、即梦、小云雀都能接

原理：给 Agent 插一个新插头

谷歌两条路各有卡点：API 参考视频只能 10 秒，Flow 审核严。碰到 15 秒以上的长镜头、四五个人来回换位的复杂场面，我就换第三方平台。

现在很多视频平台都出了命令行工具（CLI）或 MCP，本来就是给 Agent 用的。Antigravity 会跑命令，你把文档丢给它，它自己就能学会怎么用。

这条路不挑平台。 我恰好有 LibTV 的积分，所以拿它举例；你手里有哪家的积分，就接哪家。

能接哪些？文档在哪

  • LibTV：官方命令行 libtv；平台内 CLI 文档；装好后 libtv –help
  • 即梦（海外版 Dreamina）：官方命令行 dreamina；dreamina.capcut.com/tools/dreamina-cli
  • 小云雀（剪映出品）：命令行 pippit-tool-cli；npm 包 @pippit-dev/cli
  • MiniMax 海螺：官方 MCP；github.com/MiniMax-AI/MiniMax-MCP
  • 可灵：官方开放平台 API（MCP 目前是社区版）；可灵开放平台开发者文档

同一个平台里，通常还能选不同模型。LibTV 里就有 Seedance 2.5、Seedance 2.0、Wan 3.0 等好几个。

模型没有绝对的好坏，看任务。 我这个”四个虚拟角色换掉女团成员”的任务：

  • Seedance 2.5：25 秒一条，四个角色从头到尾不串、不变形，节奏稳。这个任务里最强。
  • Wan 3.0：15 秒，很多原片真人没被换掉，还留在画面里。

换个简单点的任务，结论可能不一样。

实操步骤（以 LibTV 为例）

① 登录。 让 Antigravity 跑 libtv login web，在弹出的网页里登录一次，之后它就能一直用。

② 建画布、传素材。 它会建一张画布，把参考视频（先把角落台标糊掉）和角色图传上去。

③ 选”混合参考”模式出片。 参考视频 + 角色图一起连到生成节点，记得打开声音，先出 480p 看效果。

④ 满意再升清。 在 LibTV 画布里选中那条，点高清重塑就行，这一步我自己在网页上点。

使用边界

  • 花的是第三方的积分，不是谷歌会员权益。 Seedance 2.5 480p 一条 25 秒，大约 500 积分，不便宜。
  • 每个模型时长上限不同。 Seedance 2.5 单条最长 30 秒；Wan 3.0 混合参考最长 15 秒，超了会失败退积分。
  • 文档以 –help 为准。 平台更新很快，网上的教程可能已经过时。

Tips：长片怎么接得上

尾帧续写。 积分不够一次跑完、或者想往后接一段，就把上一段成片的最后一帧截下来当参考图，连同原片接下来那段一起喂进去，再出 10 秒。

我用这个办法把 25 秒接到了 34.5 秒，衣服、光影、站位都接上了，拼起来看不出接缝。

声音别关。 为了省积分把声音关掉，成片没声音就废了一半。降成本只降分辨率和时长。

六、Pro 够不够用：我的真实账单

先说结论：跑通流程，Pro 够；拿来量产，Pro 不够。

这两天我只做了两个复刻任务（一个女团舞台、一个猫咪短片），来回调了十几版。账单是这样的：

Gemini API 赠金：10 美元，折腾完这一轮只剩 3.95 美元。

  • 大头是一开始没设分辨率，两条 720p 就花了 3.16 美元；
  • 后面全改 360p 试，花得慢多了，但来回十几版，还是花掉了一大半；
  • 另外，账单有延迟：Agent 当时查到的余额比实际多，别全信实时数字，隔天再看一眼；
  • 按 720p 一条 1.58 美元算，10 美元就是 6 条左右。拿来调试够，拿来出成片很紧。

Flow 点数：从 1047 点用到 779 点，用掉 268 点。

  • 15 秒 720p 一条 60 点，1000 点满打满算 16 条；
  • 360p 一条 20 点，能跑 50 条，但 360p 只能看动作，不能发；
  • 还有一次因为没挂上视频白扣的点数，前面 Tips 里说过。

第三方积分：Seedance 2.5 一条 25 秒 480p，约 500 积分。

  • 效果最好，也最贵；我的积分跑完 25 秒、20 秒、10 秒三条，就剩 400 多了，还得留着做高清。

所以我的判断：

  • 想先把流程跑通、偶尔做一两条好玩的：Pro 足够，Antigravity 自带的出片能力就都有了；
  • 想拿它日更、起号：Pro 的额度撑不住。同样的方法，Ultra 5x 每月 40 美元赠金、Ultra 20x 每月 100 美元，Flow 点数也多得多。

OpenPencil 从 0 到 1 保姆级手册：15 分钟做完官网、App、海报、PPT 和宣传片

今天下午，Figma、Keynote、AE 我一个都没打开。

15 分钟，我做出了一整套 AI 眼镜发布会物料：官网、3 屏 App、海报、3 页 PPT、一条 6 秒的宣传片，还有一份能直接在浏览器里打开的 React 页面。

全部在一个开源工具里完成，它叫 OpenPencil。作者@FiniYang @kayshen_xu

改一个按钮，293 个图层只动了 1 个

AI 生图交出来的是一整张图，想换个按钮颜色，多半只能重抽。OpenPencil 交出来的是设计稿，每段字、每个按钮都是能单独选中的图层。

我让 Claude Code 只把首屏「立即预订」按钮换个颜色。改之前和改之后各存一份 .op 文件，把里面 293 个图层节点逐个比对。

变了的只有那一个按钮。

.op 文件就是 JSON 文本，这次的比对就是直接拿两份文件做的。放进 Git，每次改了哪里一目了然。

15 分钟做出来的东西

叫「光迹 Lumen One」。产品图先让 GPT 画了 6 张，同一副钛合金镜框，右边镜腿一条琥珀色光条。设计、排版、动效、导出都在 OpenPencil 里，我只在 Claude Code 里说话，它通过 MCP 往画布上画。

抢先用上 v0.8.6：设计稿直接出视频

宣传片用的是 v0.8.6，新版的重头戏就是动效：关键帧、时间轴，一键导出 GIF 和 MP4。它在单独的分支上，比主分支多了 169 次提交，我等不及安装包，拉源码自己编译，6 分 53 秒编好。

导出那条 6 秒的 1080p MP4，只用了 2.7 秒，文件 438KB。导 MP4 不靠 ffmpeg，编码是它自己做的，不用另外装任何东西。

最惊艳的是 AI 能自己看动画。有个工具能把动画按时间点截成图，Claude Code 看着这些帧找出哪一帧不对，再自己改掉：

标题用的是「遮罩揭字」：外面一个裁切框，字从框底下滑上来，发布会字幕最常见的那种。跟 Claude Code 说一句就行：

能不能代替 Figma

一个人做产品，能。上面这一整套，从官网到 PPT、视频、代码，我没开过第二个设计软件。

要几个人一起改，它也有实时协作，输个配对码就能进同一张画布。

本周Github涨星前10的神级项目

发表于2026-11-22|行业观察
|浏览量:

本文转载自 X 博主 @KinhVujhfi（闲鱼梦想家） 的长文，原文链接，版权归原作者所有。

大家好，我是边炒股边学ai的一割

今天给大家带来本周Github涨星前10的神级项目。

1. dream-num/univer —本周 +7,248星（总30,944，TypeScript）

AI 办公 SDK，Luckysheet 的官方继任者。给你的产品内嵌表格/文档编辑内核（公式引擎、协同、文件处理都有），不用自己从零造轮子；新版加了 AI 操作层，agent 能直接读写单元格、触发协作事件，而不是把表格转成文本喂模型。本周全榜增量第一，而且是2022年的老仓库靠 “加 AI 层” 翻红。

2. GoogleChrome/modern-web-guidance-src — +6,858星（总9,533，TypeScript）

把最新 Web 最佳实践（HTML/CSS、性能、可访问性）整理成给编码 agent 看的 “教材” 和上下文源，让 agent 别再写2015年的过时代码。Chrome/Edge/Firefox/MDN 四方联合维护。

3. meta/astryx — +4,977星（总31,350，TypeScript）

Meta 开源的设计系统，React 19 + StyleX 底座，还停在 Beta。卖点是“为人也为 agent 而建”——组件、文档、Storybook 都按 agent 可读可改的方式组织，npm 上有 @astryxdesign/core。

4. alibaba/open-code-review — +4,492星（总54,788，Go）

阿里内部 AI 评审工具对外开源。混合架构：确定性规则流水线（快、稳）+ LLM agent（补规则扫不到的逻辑问题），精确到行级评论，内置 NPE、线程安全、XSS、SQL 注入等规则集，兼容 OpenAI/Anthropic 接口。官方口径是同模型下 token 只要 Claude Code 的约 1/9。

5. backnotprop/plannotator — +3,468星（总13,900，TypeScript）

Agent 工作台。把 agent 的计划、规格、markdown/HTML 稿件、diff 和 PR 收进一个界面，你在上面批注、审阅、决定，再一键把反馈回传给 agent。已接入 Amp、Claude Code、Codex、Copilot、Droid、Gemini CLI 六家。

6. ag-ui-protocol/ag-ui — +3,455星（总20,820，TypeScript）

AG-UI 协议：定义 agent 和前端应用怎么对话的开放规范，让 agent 的状态、工具调用、流式输出能直接渲染进你的界面。npm @ag-ui/core + PyPI 双端 SDK，MIT 许可。

7. tradermonty/claude-trading-skills — +3,385 星（总 7,404，Python）

给股票投资者和交易员用的 Claude Code 技能包：行情分析、技术图表绘制、财经日历、选股筛选器、交易策略开发，一整套塞进 agent 里调用。

8. ChromeDevTools/chrome-devtools-mcp — +3,229 星（总 58,542，TypeScript）

Chrome 官方出品的 DevTools MCP server + CLI 双形态，让 Antigravity、Claude、Cursor、Copilot 这类编码 agent 能真正控制并检查一个活的 Chrome：抓性能 trace 给优化建议、看网络请求、截图、读控制台（带 source-map 栈）。底层是 Puppeteer。

9. we-promise/sure — +3,226星（总16,883，Ruby）

开源自托管的个人财务 App（可以理解为 Maybe 财务应用的社区继任版）：净资产看板、账户聚合、预算与交易分类、投资持仓跟踪，数据放自己服务器上。

10. mvanhorn/last30days-skill — +3,179星（总71,371，Python）

一个 “近 30 天调研”agent skill：跨 Reddit、X、YouTube、Hacker News、Polymarket 和普通网页抓取某个话题的讨论，再综合成一份带出处的摘要，适合新品调研、舆情摸底。

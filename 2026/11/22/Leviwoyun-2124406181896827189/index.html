Antigravity 11 篇教程合集，从入门到多 Agent 实战

发表于2026-11-22|行业观察
|浏览量:

本文转载自 X 博主 @Leviwoyun（Levi 卧云） 的长文，原文链接，版权归原作者所有。

gemini 最近更新太猛了，谷歌又频出 BUG 订阅，不少朋友都已上车 gemini，却又头疼 Antigravity，不知道正确的使用方式。

所以我把几位大佬写过的优质中文教程好好理了一遍：从安装、汉化、避坑，到偷懒指令和多 Agent 实战。不用一口气读完，找到你踩坑的地方，翻对应的那篇就行。（本文由 bot 与 Antigravity 参与整理编写）

一、重中之重，如果你想低价上车gemini，那么我强烈推荐你看磊哥这一篇文章，我自己也实测成功👇

二、会员开了，Antigravity 还是登不上？看看这篇

开通了 Google AI Pro，节点也换了，还是提示地区不支持，先别反复折腾网络

会员额度和地区限制：登不上，是和 Google 账号关联地区有关，不只是当前网络的问题。Antigravity 本身有免费档，想测试反重力能不能登上，可以先用免费账号去练手。文中给出了账号地区的查询方式、官方更正入口，以及后续网络设置的排查过程。

三、从下载安装到第一次跑通 刚接触反重力，看 Chasen 这篇

客户端、命令行、IDE 插件怎么选？工作目录怎么设？MCP 怎么连？远程怎么控？这篇全都有。
先建立全局概念，省得后面遇到一个新词就得退出来搜半天。 新手第一步的目标极简单：能打开、能下指令、知道去哪看结果

四、订阅、插件、模型、排错看这里

登录转圈、资格校验不过、明明网页端掏了钱客户端却依然显示免费额度……这类问题，雪瑜这篇都总结了，重点翻翻安装、模型选择、插件，以及各种登录/额度识别的排错招数。

五、四种反重力汉化包

Chasen 整理了 4 个主流开源汉化方案，各个方案的安装门槛和汉化深度不太一样，有的还支持一键切回英文。 装一个就行

六、额度、重置监控看板插件

3 个很贴心的小插件：额度看板、汉化、多账号切换。 最推荐先把额度看板加上。

七、命令行合集

需求一团乱麻想先理理思路？改代码前想让它先交个方案？主任务正跑着突然想顺嘴插问一句？想回退任务？ 这些高频场景，根本不需要你苦哈哈写小作文教它做人。用上这些指令👇

八，命令知道是一回事，怎么用得丝滑又省钱？

大动干戈前先对齐需求定计划；临时加塞问题走专线别搅乱主干；眼看跑偏了赶紧回滚；一段活干完麻利做记忆压缩（/compact）。以及 CLI 无头挂机跑法。实用性拉满。

九、别为了炫技硬上多 Agent，先想好怎么分工

多 Agent 绝不是“一口气多开几个会话窗口”就能自动提效的。 切片、写码、质检、收尾，做好分工。这篇把 Orchestrator（指挥官）、Swarm（蜂群）以及开源的 dsh-crew 分析的透透的，还给了实战提示词模板。👇

十、想搞全自动做视频？看高手怎么把一串工具链打通

Antigravity 自身不会生成视频，但它是一个极其强悍的“工头”，能把前后各个工具按工序串起来。 Leaf 这篇展示了一条完整的 AI 出片流水线：拆解对标片、人物定妆、打磨提示词、提交生图生视频、自动拉回本地、拼原声、再抽帧质检。文章里还附了现成的 Agent 指令

十一、稳定的自动化内容产线

批量复制输出内容，个人“内容流水线”：Antigravity 稳坐中控台管大纲、写分镜、派活发单，生成工具老实干苦力，后面再挂审片、局部返工重做与自动归档。 工程化思路：复用 Skill、对齐时间戳打标签、只返工翻车的那几个片段、严设最大重试次数。

超全 100 种建站方式，从零代码、笔记建站到 Rust，总有一种适合你

发表于2026-11-19|行业观察
|浏览量:

本文转载自 X 博主 @0xlangeai（蓝哥AI） 的长文，原文链接，版权归原作者所有。

大家好，我是想风！今天来看建站这件事，100 种方式一次摊开！

想做个网站，搜一圈下来，WordPress、Hugo、Next.js、Notion、Webflow……名字一个比一个多。

选择太多，最后可能一个都没开始。

这篇把 100 种建站方式分成九类，从拖拖拽拽的零代码，到笔记一键发布，再到用 Go、Python、Rust 手写，每一种讲清是什么、适合谁。

不用全看。可以先看第一节的选择表，找到自己那一格，再跳到对应章节。

  • 一、先说结论：按需求挑

一、先说结论：按需求挑

建站方式没有好坏，只有合不合适，适合自己的才是最好的。

判断标准就三个：会不会写代码、想花多少钱、内容放在哪写。

  • | 你的情况 | 推荐 | 编号 |
  • | :— | :— | :— |
  • | 只想要一个个人主页，十分钟搞定 | Carrd、Framer | 6、5 |
  • | 不会代码，想做漂亮的官网 | Webflow、Framer、Wix | 4、5、2 |
  • | 写博客，愿意学一点命令行 | Hugo、Astro + GitHub Pages | 43、48 |
  • | 平时用 Obsidian / Notion 记笔记 | Quartz、Notion Sites | 24、21 |
  • | 出海卖货 | Shopify | 7 |
  • | 写 Newsletter 顺便有个站 | Substack、beehiiv | 9、10 |
  • | 做开源项目文档 | VitePress、Docusaurus、MkDocs | 49、52、54 |
  • | 想学编程，顺便建站 | 纯 HTML → Astro → Next.js | 63、48、65 |
  • | 不想写代码，但想要代码 | Claude Code、v0、Lovable | 17、13、15 |
  • | 国内读者为主，要后台管理 | Halo、Typecho、WordPress | 33、34、31 |

二、零代码平台（1-12）

不用写一行代码，注册账号、选模板、拖拽、绑定域名，网站就上线了。

代价是按月付费，数据和样式都在别人平台上，想搬家不容易。

1. WordPress.com

WordPress 官方托管版，不用自己买服务器。和开源的 WordPress（31 号）是两回事——一个是租房，一个是自己盖房。

2. Wix

拖拽自由度高，元素想放哪放哪，模板多。适合小商家、工作室官网。

3. Squarespace

模板以审美出名，摄影师、设计师、餐厅用得多。自由度不如 Wix，但很难做丑。

4. Webflow

可视化版的前端开发，盒模型、Flex、Grid 全都摆在面板上。学会了接近手写 CSS 的控制力，门槛也比前面几个高。

5. Framer

从设计工具转型来的建站平台，动效做得好，做产品落地页、个人作品集很快。

6. Carrd

只做单页网站。个人主页、产品预告页、活动报名页，一页就够的场景首选，价格便宜。

7. Shopify

跨境电商建站的事实标准。商品、支付、物流、主题、插件一条龙，月费加交易抽成。

8. Google Sites

谷歌免费的简易建站，和 Google Docs、Drive 打通。做团队内部页、课程页够用，设计上别抱期待。

9. Substack

写 Newsletter 的平台，每个作者自带一个网站。文章同时发邮件、上网页，付费订阅内置。

10. beehiiv

和 Substack 同一赛道，更偏增长：推荐网络、广告变现、数据分析做得重。

11. Hashnode

面向开发者的博客平台，可以绑定自己的域名，支持把文章备份到 GitHub。

12. Strikingly

主打一页式网站，上手和 Carrd 差不多，模板偏商务。

三、AI 建站（13-20）

这两年最大的变化：不会写代码，也能拿到代码。

用大白话描述想要什么，AI 生成页面，看着不满意就接着说。和零代码平台最大的区别是——产出的是真代码，可以带走。

13. v0

Vercel 出品，描述需求生成 React + Tailwind 界面，一键部署到 Vercel。

14. Bolt.new

StackBlitz 出品，在浏览器里跑完整开发环境，AI 写完直接预览、直接部署。

15. Lovable

对话生成全栈应用，前端加数据库都给配好，适合做带登录、带数据的小产品。

16. Replit

在线编程平台，内置 AI Agent。从一句需求到可访问的网址，全在浏览器里完成。

17. Claude Code

终端里的 AI 编程助手。在自己电脑上建项目，说一句「用 Astro 搭一个博客」，它装依赖、写页面、跑预览。代码全在本地。

18. Codex

OpenAI 的编程 Agent，用法和 Claude Code 类似，可以在终端里用，也可以在云端跑任务。

19. Cursor

带 AI 的代码编辑器。适合愿意看一眼代码的人：AI 写，你审，哪里不对指哪里。

20. Durable

面向小商家的 AI 建站，填几个问题生成整站，文案、图片一起出。和 13-19 不同，它产出的是平台里的网站，不是代码。

四、笔记建站（21-30）

笔记写好了，直接变成网站。

最适合不想多维护一套系统的人——写作在笔记软件里，发布是顺手的事。

21. Notion Sites

Notion 自带的发布功能，页面一键公开成网站，可以绑定自定义域名。

22. Super

把 Notion 页面包装成正经网站：自定义域名、主题、SEO 设置、更快的加载速度。Notion 建站党常用。

23. Obsidian Publish

Obsidian 官方付费发布服务。选几篇笔记点发布，双向链接、关系图谱都保留。

24. Quartz

开源免费，把 Obsidian 笔记库变成网站，双链、反向链接、关系图、全文搜索都有。部署到 GitHub Pages 或 Cloudflare Pages 不花钱。

25. Obsidian Digital Garden

Obsidian 社区插件，笔记里加一个属性标记就发布，配合 Vercel 或 Netlify 自动上线。

26. Logseq

大纲式笔记，可以把公开的页面导出成静态网站，适合做个人知识库。

27. TiddlyWiki

整个网站就是一个 HTML 文件。笔记、样式、程序全在里面，双击就能打开，丢到任何地方就能访问。

28. 语雀

蚂蚁出品，知识库可以设为公开，自带目录、搜索、评论。国内访问快，适合中文教程和团队文档。

29. 飞书知识库

飞书文档开启互联网公开后，就是一个能被访问的页面。团队对外发帮助文档很方便。

30. Craft

苹果生态里颜值很高的笔记软件，文档可以一键分享成网页。

五、开源 CMS·自己部署（31-42）

CMS 就是内容管理系统——带后台的网站。登录后台写文章、传图片、改菜单，不用碰代码。

开源意味着免费、数据在自己手里，代价是要自己买服务器、自己更新、自己负责安全。

31. WordPress

PHP 写的，全世界最多网站在用的 CMS。主题、插件多到用不完，博客、企业站、电商（配合 89 号 WooCommerce）都能做。

32. Ghost

Node.js 写的，专注写作和会员订阅。编辑器干净，内置 Newsletter 和付费墙。

33. Halo

Java 写的国产博客系统，中文文档齐全，用 Docker 部署很方便，主题和插件生态在中文圈很活跃。

34. Typecho

PHP 写的国产轻量博客，程序很小，对服务器要求低，老牌中文博客用得多。

35. Drupal

PHP 写的重型 CMS，政府、高校、大型机构用得多。功能强，学习成本也高。

36. Joomla

PHP 写的老牌 CMS，定位在 WordPress 和 Drupal 之间。

37. Grav

PHP 写的无数据库 CMS，内容全是 Markdown 文件，备份就是复制文件夹。

38. Strapi

Node.js 写的无头 CMS。「无头」就是只管后台和接口，不管前台长什么样——前台用 Next.js、Astro 随便接。

39. Directus

把任何一个 SQL 数据库直接变成带后台、带接口的 CMS，适合已经有数据库的项目。

40. Payload

TypeScript 写的无头 CMS，可以直接装进 Next.js 项目里，前后台一个仓库。

41. Decap CMS

以前叫 Netlify CMS。给静态网站加一个网页后台，写完的文章直接提交到 Git 仓库。适合想要后台、又不想要数据库的人。

42. WriteFreely

Go 写的极简博客，支持联邦协议，文章能被 Mastodon 等去中心化社交网络的用户关注。

六、静态站点生成器：按编程语言分（43-62）

静态站点生成器，就是把 Markdown 文件「编译」成一堆 HTML 的工具。

没有数据库、没有后台，生成的文件丢到任何地方都能访问，免费托管、速度快、几乎不会被黑。写博客、做文档的首选。

用什么语言写的生成器，决定了你改主题、写插件时要碰什么语言。不想改，就不用管。

Go

43. Hugo

速度出了名的快，几千篇文章秒级生成。单个程序文件，装上就能用，不用配语言环境。

Ruby

44. Jekyll

GitHub Pages 原生支持的生成器，静态博客的老前辈。推到仓库，GitHub 自动帮你生成。

45. Bridgetown

从 Jekyll 演化出来的现代版，加了前端打包、组件这些新东西。

JavaScript / Node.js

46. Hexo

中文圈最流行的博客生成器之一，主题多，中文教程多。

47. Eleventy (11ty)

灵活、零客户端 JS，支持十几种模板语言，喜欢简洁的前端开发者很爱。

48. Astro

当下最火的内容站框架。页面默认不带 JavaScript，需要交互的部分再单独加载，React、Vue、Svelte 组件可以混着用。

49. VitePress

Vue 官方的文档生成器，基于 Vite，启动快，Vue 生态的文档几乎都用它。

50. VuePress

VitePress 的前辈，老项目还在用，新项目更推荐 49。

51. Gatsby

React + GraphQL 的生成器，几年前很火，现在热度下降，新项目一般选 Astro 或 Next.js。

52. Docusaurus

Meta 出品的文档框架，自带版本管理、多语言、博客，大量开源项目的文档站用它。

53. Lume

运行在 Deno 上的生成器，配置简单，Deno 用户的首选。

Python

54. MkDocs

Python 文档生成器，配上 Material 主题，是技术文档的颜值担当。

55. Sphinx

Python 官方文档就是它做的，擅长超长技术文档、API 文档、交叉引用。

56. Pelican

Python 写的博客生成器，用 Markdown 或 reStructuredText 写作。

57. Nikola

Python 写的生成器，支持 Jupyter Notebook 直接变成文章，适合数据分析博客。

Rust

58. Zola

单个程序文件，和 Hugo 一样不用配环境，模板语法更好懂。

59. mdBook

把 Markdown 做成在线书，Rust 官方教程就是它做的。写电子书、教程合集合适。

其他语言

60. Hakyll

Haskell 写的，配置本身就是一段 Haskell 程序，函数式编程爱好者的玩具。

61. Quarto

科研和数据分析专用，Python、R、Julia 代码和图表直接写进文章，生成网站、书、幻灯片。

62. Franklin.jl

Julia 写的生成器，数学公式和代码运行结果支持得好。

七、前端框架（63-74）

到这一层，网站不光是内容，还能有交互：登录、表单、搜索、动态数据。

学习成本明显上来了，但能做的事也没有上限。

63. 纯 HTML + CSS

一个 index.html 就是一个网站。

不用框架，不用安装，记事本都能写。学建站从这里开始最扎实——后面所有框架，最后吐出来的都是 HTML。

64. Vite + React

最常见的单页应用起手式。注意：纯单页应用对搜索引擎不友好，做内容站要配合服务端渲染。

65. Next.js

React 全栈框架，服务端渲染、静态生成、接口路由都有。出海 SaaS 官网和产品用得极多。

66. Nuxt

Vue 版的 Next.js，喜欢 Vue 就选它。

67. SvelteKit

Svelte 的全栈框架，写法简洁，打包体积小。

68. React Router（原 Remix）

Remix 并入了 React Router，主打 Web 标准：表单、请求、缓存都按浏览器原生的方式来。

69. SolidStart

Solid 的全栈框架，写法像 React，性能更好。

70. Qwik

主打「可恢复」——页面几乎不用加载 JavaScript 就能交互，追求极致首屏速度。

71. Angular

谷歌的企业级框架，大公司后台系统常见，个人建站偏重。

72. Fresh

Deno 的全栈框架，默认不往浏览器发 JavaScript，按需给组件加交互。

73. Hono

超轻量的网页框架，能跑在 Cloudflare Workers、Deno、Bun、Node 上，配合 JSX 就能写页面。

74. htmx

不写 JavaScript 也能做交互：在 HTML 标签上加几个属性，点击按钮就能局部刷新。后端用什么语言都行，是对前端框架的一记反叛。

八、后端语言（75-88）

前面多数方式偏前端。这一类反过来：服务器端用模板拼出 HTML，数据库、登录、后台全在一个项目里。

建站顺便学一门后端语言，这里挑你想学的那门。

75. Django（Python）

自带后台管理、用户系统、数据库工具，号称「给有截止日期的完美主义者」。做内容站、带后台的网站很快。

76. Flask（Python）

极简，几行代码就能跑起一个网站，需要什么再装什么。

77. FastAPI（Python）

主打写接口，配合 Jinja 模板也能出页面。AI 项目的后端很多用它。

78. Ruby on Rails（Ruby）

约定大于配置，一行命令生成增删改查，独立开发者做产品的老牌利器。

79. Laravel（PHP）

PHP 里最流行的框架，文档好，生态全，从登录到支付都有官方方案。

80. net/http（Go）

Go 标准库自带网页服务器和模板，不装任何框架就能建站，编译成一个文件丢到服务器上就跑。

81. Spring Boot（Java）

Java 后端的标准答案，企业项目最常见。个人建站偏重，但学会了就业面广。

82. Ktor（Kotlin）

JetBrains 出品，轻量的 Kotlin 网页框架。

83. ASP.NET Core（C#）

微软的网页框架，配合 Blazor 可以用 C# 写前端交互，不碰 JavaScript。

84. Axum（Rust）

Rust 生态最主流的网页框架之一，性能和稳定性拉满。

85. Leptos（Rust）

用 Rust 写全栈：服务器端渲染加浏览器端 WebAssembly，一门语言管到底。

86. Phoenix（Elixir）

配合 LiveView，服务器直接推送页面更新，不写前端也能做实时交互。

87. Express（Node.js）

Node.js 最经典的网页框架，简单直接，资料最多。

88. Vapor（Swift）

用 Swift 写服务器，iOS 开发者想做配套网站时最顺手。

九、电商·单页·链接页（89-94）

89. WooCommerce

WordPress 的电商插件，把博客变成网店。比 Shopify 自由，也更需要自己折腾。

90. Medusa

TypeScript 写的开源电商后端，前台自己做，适合想深度定制的独立站。

91. Saleor

Python 写的开源电商平台，用 GraphQL 提供接口，面向中大型项目。

92. Gumroad

卖数字产品的平台：电子书、课程、模板、设计素材。每个卖家自带一个商品页。

93. Linktree

一页放所有链接，社交媒体简介里那个「link in bio」。类似的还有 bio.link 等。

94. GitHub 个人主页 README

新建一个和用户名同名的仓库，里面的 README 就会显示在 GitHub 个人主页上。程序员的第二张名片。

十、极客玩法（95-100）

不为效率，为乐趣。

95. Emacs Org-mode

用 Org-mode 写笔记，内置的 org-publish 直接导出整站 HTML。Emacs 用户的终极闭环。

96. Shell 脚本

一个 Bash 脚本遍历 Markdown 文件，拼成 HTML。网上有现成的单文件博客脚本，几百行就是一个博客引擎。

97. Streamlit

几十行 Python 就能把数据分析、AI 小工具做成网页，不用写一行前端。

98. PocketBase

Go 写的单文件后端：数据库、用户登录、文件存储、管理后台全在一个程序里。前端随便配，小项目的后端几分钟搞定。

99. OpenResty

Nginx 加 Lua，直接在网页服务器里写逻辑，高并发场景用得多。

100. Elm

纯函数式的前端语言，号称「编译通过就不会运行时报错」。写起来像解谜。

十一、建好了放哪：上线方式

网站做好了，还需要一个地方让别人访问。按类型分三种：

  • | 类型 | 代表 | 适合 |
  • | :— | :— | :— |
  • | 静态托管 | GitHub Pages、Cloudflare Pages、Netlify、Vercel | 43-62 的静态站、Astro、纯 HTML，基本免费 |
  • | 应用平台 | Vercel、Railway、Render、Fly.io | Next.js 这类全栈应用、带后端的小项目 |
  • | 自己的服务器 | 云服务器 VPS + Docker | 31-42 的 CMS、75-88 的后端项目 |

平台官网：GitHub Pages、Cloudflare Pages、Netlify、Vercel、Railway、Render、Fly.io。

最省事的组合：代码推到 GitHub，连上 Cloudflare Pages 或 Vercel，以后每次推送自动上线。

再配一个自己的域名，网站才算真正属于你。从买域名到上线的完整步骤，见 [[超简单建站教程大全，从域名到上线，妈妈都能学会]]；用 Notion 建站，见 [[Notion 从入门到建站]]。

十二、常见坑

坑一：框架换来换去，一篇文章没写。

建站最大的坑不在技术，在拖延。先用最简单的方式上线，内容攒够了再考虑换。

坑二：平台锁定，搬家很痛。

零代码平台（1-12）和部分笔记平台，样式和数据都在别人手里，导出常常只剩一堆乱格式。长期要写的内容，尽量用 Markdown 存一份在自己手里。

坑三：大陆服务器要备案。

网站放在中国大陆的服务器上，要先做 ICP 备案才能用域名访问。读者在海外，或者不想备案，就选海外服务器和海外托管平台。部分海外托管平台在国内访问速度不稳定，上线后用国内网络实际打开测一下。

坑四：WordPress 不更新，等着被黑。

WordPress 用的人最多，也最常被攻击。核心程序、主题、插件都要及时更新，用不到的插件直接删掉。

坑五：单页应用，搜索引擎看不见。

纯前端渲染的网站（64 号那类），搜索引擎抓到的可能是一个空页面。要做 SEO，选静态生成或服务端渲染（Astro、Next.js、Nuxt 等）。

坑六：免费额度用超。

托管平台的免费套餐都有流量、构建次数、函数调用的上限。网站突然火了，或者被刷流量，账单可能吓一跳。上线前看一眼平台的限额说明，能设消费上限的就设上。

最后

100 种方式，真正需要的只有一种。

不会代码，选零代码平台或 AI 建站； 爱记笔记，选 Quartz 或 Notion； 想学技术，从一个 index.html 开始。

先上线，再优化。

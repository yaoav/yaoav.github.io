主流 Agent /斜杠命令全览

发表于2026-11-19|行业观察
|浏览量:

本文转载自 X 博主 @Sukiea1008（Su） 的长文，原文链接，版权归原作者所有。

这篇收录整理了 Claude Code、Codex、Grok Build、Cursor 和 Antigravity 的斜杠命令。

我把各家都通用的放在最前面，后面按 Agent 分开，你可以快速查漏补缺你常用 Agent 里一些你可能需要但是之前都疏漏了的斜杠命令。

01｜跨工具常用命令

同名命令在各家的细节不完全相同，以各家完整表为准。

  • /goal：一直做到目标完成（五家都有，Cursor 正在逐步放开）
  • /plan：先做规划再开始改（五家都有，Cursor 仅 CLI）
  • /model：切换或选择当前模型（Cursor、Antigravity 仅 CLI）
  • /btw：旁路问一句，少打断主对话（Codex 桌面/IDE 用 /side，Cursor 仅编辑器）
  • /compact：压缩上下文（Cursor 用 /summarize，Antigravity 没有）
  • /clear 或 /new：清空或新开一场对话（名字不统一，Codex IDE 没有）
  • /resume：打开以往会话并继续（Codex 桌面/IDE 没有）
  • /fork：把当前对话复制成新会话（Antigravity 公开目录没有）
  • /mcp：管理 MCP 连接（Grok 叫 /mcps）

02｜Claude Code

在提示框输入 /，就会出现命令菜单。

帮助、状态和用量

  • /help：查看当前能用的命令
  • /status：查看账号、模型和版本
  • /usage：查看花费和用量（/cost、/stats 同）
  • /usage-credits：额度用完时调整或申请加量
  • /rate-limit-options：碰到限额时看还能怎么继续
  • /insights：根据近期会话生成使用报告
  • /upgrade：打开升级页面
  • /release-notes：查看当前版本更新说明

会话、上下文和回退

  • /clear：开一场空的新对话（/new 同）
  • /compact：把对话做成摘要，腾出上下文
  • /autocompact：设置何时自动压缩上下文
  • /context：查看当前上下文用量
  • /btw：旁路问一句，不写进主对话
  • /rewind：回到更早的检查点
  • /resume：接着上次的对话继续
  • /branch：从当前点分出一条分支再试
  • /fork：把当前对话复制成新的后台会话
  • /rename：给当前会话改名
  • /recap：生成当前会话的短摘要
  • /copy：复制最近一次回复
  • /export：把对话导出成文件
  • /stop：停下当前挂着的后台会话
  • /exit：退出 CLI（挂在后台时只断开）
  • /restart：重启并回到当前会话

模型、推理和回答

  • /model：查看或切换当前模型
  • /effort：调整思考力度
  • /fast：打开或关闭 fast mode
  • /advisor：关键节点再问另一个模型
  • /output-style：切换输出风格
  • /voice：打开或关闭语音输入

规划、目标和执行

  • /plan：进入 Plan Mode
  • /goal：设目标，一直做到条件满足
  • /loop：按间隔反复跑同一条提示
  • /schedule：创建或管理云端定时任务
  • /run：真正启动并操作一遍项目应用
  • /verify：构建并跑一遍，确认改动生效
  • /simplify：把最近改过的文件写得更干净

改代码和审查

  • /diff：查看未提交改动和每轮差异
  • /code-review：审查 diff、PR 或分支（/review 同）
  • /security-review：检查当前分支的安全问题
  • /ultrareview：在云端做更深的多智能体审查
  • /autofix-pr：盯着当前 PR，有问题就改并推送

并行和工作流

  • /agents：创建或管理 subagents
  • /list-agents：列出可发消息的会话和队友
  • /subtask：分出一个后台 subagent 去做这件事
  • /tasks：查看并管理后台工作
  • /background：把当前会话摘到后台继续跑
  • /batch：把大改拆成多份，并行做
  • /workflows：查看和管理正在跑的工作流
  • /workflow-authoring：查看动态工作流的写法说明
  • /deep-research：分头搜索并写成带引用的报告

记忆、项目和目录

  • /init：摸一遍代码库，生成 CLAUDE.md
  • /memory：查看或编辑当前 CLAUDE.md
  • /add-dir：再加一个可访问的工作目录
  • /cd：把这场会话搬到新的工作目录
  • /import：从 Codex、Gemini 或 Cursor 迁入配置

权限、设置和界面

  • /permissions：设置哪些工具需要你批准
  • /sandbox：查看或调整沙箱设置
  • /config：打开或修改设置
  • /theme：更换颜色主题
  • /color：给当前会话提示条换颜色
  • /tui：切换终端界面渲染方式
  • /terminal-setup：配置终端换行和剪贴板
  • /keybindings：打开键盘快捷键文件
  • /statusline：配置状态栏
  • /fewer-permission-prompts：把常见只读操作写入允许列表
  • /auto-mode-setup：起草并写入 auto mode 配置
  • /update-config：用自然语言改 settings.json
  • /privacy-settings：查看或更新隐私设置
  • /focus：打开或关闭专注视图

MCP、插件和技能

  • /mcp：管理 MCP 连接
  • /plugin：安装、启用或停用插件
  • /plugin-authoring：查看如何编写插件
  • /reload-plugins：重新加载插件
  • /skills：列出当前可用的技能
  • /reload-skills：重新加载技能
  • /run-skill-generator：为项目生成 /run 和 /verify 技能
  • /skill-doctor：检查技能安装或配置问题
  • /hooks：查看 hook 配置
  • /chrome：配置 Claude in Chrome
  • /claude-in-chrome：在 Chrome 里交给 Claude 一项任务
  • /claude-api：加载 Claude API 参考资料
  • /setup-bedrock：配置 Amazon Bedrock
  • /setup-vertex：配置 Google Vertex AI

设计与产物

  • /design：按说明做界面或设计稿
  • /design-login：登录 Claude Design
  • /design-sync：把设计相关资源同步进来
  • /slides：按说明做幻灯片
  • /dataviz：给图表和仪表盘提供设计指引
  • /artifacts：列出、打开或分享产物
  • 其他：/design consent、/design revoke、/artifact-capabilities、/artifact-diagramming

账号和远程

  • /login：登录 Anthropic 账号
  • /logout：退出当前账号
  • /desktop：把当前会话接到桌面应用
  • /mobile：显示二维码，下载手机应用
  • /remote-control：允许从 claude.ai 远程接着操作
  • /remote-env：选择云端会话的默认环境
  • /teleport：把一场云端会话拉到当前终端
  • /web-setup：给云端会话绑定 GitHub 账号
  • /install-github-app：安装或配置 GitHub 应用
  • /install-slack-app：安装或配置 Slack 应用
  • /ide：管理 IDE 集成
  • /team-onboarding：生成一份团队上手指南
  • /feedback：向官方反馈问题
  • /doctor：检查安装和设置问题

其他

/scroll-speed、/radio、/stickers、/passes、/powerup、/heapdump、/debug、/bug

参考：https://code.claude.com/docs/en/commands

03｜Codex

有 CLI、ChatGPT 桌面端、IDE 三张官方表，分开看。Codex 的命令不适用于 ChatGPT 网页。

CLI

权限、模型和设置

  • /permissions：设置哪些事可以先做、哪些先问你
  • /model：选择当前模型和推理力度
  • /fast：打开或关闭 Fast 档
  • /plan：进入 plan mode，先出方案再改
  • /goal：设置或管理一个持续目标
  • /experimental：开关实验功能
  • /daybreak：符合条件时开关 Daybreak
  • /vim：给输入框打开或关闭 Vim 模式
  • /config：搜索并修改终端偏好
  • /keymap：重新绑定 TUI 快捷键
  • /theme：选择语法高亮主题
  • /statusline：配置底部状态栏
  • /title：配置终端窗口标题
  • /tui：选择下次启动时的终端模式
  • /memories：设置这场对话能不能用记忆

会话流转

  • /clear：清掉界面，并开一场新对话
  • /new：在同一个 CLI 里新开一场对话
  • /resume：从已保存的会话里接着继续
  • /rename：给当前对话改名
  • /archive：把当前会话归档
  • /delete：永久删除当前会话
  • /fork：把当前对话分叉成一场新对话
  • /side、/btw：开一个侧边对话，不打断主对话
  • /compact：把对话做成摘要，腾出上下文
  • /recap：生成摘要，但不压缩上下文
  • /export：把对话导出成文件
  • /copy：复制一条回复、代码或引用
  • /quit、/exit：退出 CLI
  • /logout：退出登录

工作区和审查

  • /init：在当前目录生成 AGENTS.md
  • /ide：把 IDE 里的文件和选区带进下一句
  • /mention：把某个文件或文件夹附到对话里
  • /cd：更换当前会话的工作目录
  • /pwd：显示当前工作目录（/cwd 同）
  • /worktree：在由 Codex 管理的 worktree 里工作
  • /diff：查看 Git 差异
  • /review：审查当前工作区里的改动
  • /status：显示会话配置和 token 用量
  • /usage：查看账号用量或限额重置
  • /approve：自动审查拒绝后，批准再试一次

扩展和后台

  • /mcp：列出已配置的 MCP 工具
  • /apps：浏览 connectors 并插进提示
  • /plugins：浏览和管理插件
  • /hooks：查看和管理生命周期 hooks
  • /skills：浏览并使用技能
  • /presets：保存并再次运行常用提示
  • /import：从 Claude Code 或 Cursor 导入设置
  • /agents：打开 agent 指挥中心并切换
  • /subagents：切换到某个 subagent 线程
  • /ps：查看后台终端和最近输出
  • /stop：停掉当前会话拉起的全部后台终端
  • /daemon：管理 Codex 自己的本地服务器
  • /app：把当前会话接到 ChatGPT 桌面应用
  • /voice：开始或结束语音对话
  • /feedback：发送反馈，或保存诊断包

其他：/raw、/setup-default-sandbox、/pets、/debug-config、/warnings

ChatGPT 桌面端

官方 28 条。和 CLI 用途相同的有：/approve、/compact、/fast、/feedback、/fork、/goal、/init、/mcp、/memories、/model、/plan、/review、/side、/status、/usage、/worktree。

这个端还有：

  • /chat：开始新对话前，选一场已有对话

  • /cloud-environment：为这场对话选择云端环境
  • /ide-context：打开或关闭共享的 IDE 上下文
  • /local：在当前本地项目里跑这场对话
  • /new：在同一个本地工作区开一场空白对话
  • /pet：叫醒或收起桌面宠物
  • /pin：置顶或取消置顶当前对话
  • /project：为新对话选择一个 project
  • /reasoning：为当前对话选择推理力度

IDE

官方斜杠命令 21 条，与桌面端大多相同，少了 /archive、/chat、/new、/pet、/pin、/rename、/usage。命令面板里还有 6 条动作，那些不是斜杠命令。

参考：https://learn.chatgpt.com/docs/developer-commands?surface=cli

06｜Antigravity

公开目录 16 条，App 和 CLI 共用。CLI 另外还有会话和设置类命令，包括 /model。/automation、/generative_ui 仅 App。

公开目录（App 与 CLI 共用）

  • /swarm：由 worker 和 verifier 拆分任务并协作（Pro 或 Ultra）
  • /goal：自主执行，直到目标完成，中途不暂停
  • /plan：调研代码、对齐需求，并起草可评审的计划
  • /grill-me：一次只问一个问题，用来对齐设计和边界情况
  • /learn：把这次会话的纠正沉淀成 Rules 或 Skills
  • /agy-customizations：加载定制说明，方便创建或修复配置
  • /plugin：打开插件管理器，或管理、创建插件
  • /automation：设置一项定时后台自动化（仅 App）
  • /schedule：把一条指令设成定时或周期执行
  • /browser：启动浏览器子智能体，做界面测试或截图
  • /btw：在只读分叉里旁路问一句，不暂停当前工作
  • /generative_ui：生成可交互的图表或说明组件（仅 App）
  • /antigravity-guide：根据官方文档回答怎么使用 Antigravity

  • /resume：打开会话选择器，加载以前的对话
  • /rewind：把对话历史退回到更早的一条消息
  • /rename：给当前会话改名
  • /exit：关闭 TUI，回到原来的终端
  • /copy：复制最近一次回复，或最近一次 /btw 的回答

模型和设置

  • /model：选择常用推理模型，并在会话之间记住
  • /effort：查看或设置当前模型的推理力度
  • /config：打开设置面板
  • /permissions：打开工具权限管理
  • /keybindings：打开快捷键编辑器
  • /statusline：打开状态栏自定义
  • /title：打开、关闭或设置窗口标题更新

工作区和工具

  • /add-dir：把一个目录加进当前工作区
  • /open：用系统默认编辑器打开这个路径
  • /context：打开上下文用量面板
  • /diff：打开差异查看器
  • /codesearch：打开代码搜索面板
  • /agents：打开 Agent Manager，切换自定义 agent
  • /artifact：打开产物评审面板
  • /tasks：打开任务管理，查看后台执行日志
  • /swarm board：全屏打开 live swarm board
  • /mcp：打开 MCP 服务器管理
  • /skills：浏览已加载的技能
  • /hooks：浏览当前的脚本 hooks
  • /remote-control：打开或关闭 Remote Control
  • /voice：用语音对话，或口述一条提示

账号和帮助

  • /help：打开帮助，查看命令和快捷键
  • /changelog：打开更新说明
  • /credits：查看剩余 AI 额度和购买入口
  • /usage：查看模型配额用量
  • /feedback：打开反馈面板
  • /logout：退出登录，并清除本地凭证

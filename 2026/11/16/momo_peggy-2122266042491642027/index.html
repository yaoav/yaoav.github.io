被问爆的 AI 自媒体工作台，我直接开源了：一个人管 7 个平台的发布 + 监控系统｜麦田

发表于2026-11-16|行业观察
|浏览量:

本文转载自 X 博主 @momo_peggy（夏林果的出海日记） 的长文，原文链接，版权归原作者所有。

我一个人，管着七个平台。

B站、抖音、小红书、视频号、YouTube、X，再加上我自己的知识站。每期视频都要发一遍，每个平台的数据每天都要看一遍。

前几天我随手在推上发了一张自己工作台的截图，就是我管这七个平台用的那个页面，本来就是想晒一下。结果评论和私信里问得最多的居然是同一句话：这个界面怎么做的，能不能给我一份。

还有好多朋友说，就是喜欢这个审美，喜欢这个样式。

说实话我挺意外的。那行吧，既然大家喜欢，干脆开源。

它叫麦田。

名字没什么讲究，就是我自己天天在里面「种内容、收数据」。

我是一个自媒体博主，自己还有一个知识站，平时主要做长视频。同一条视频，要发到六个平台，每个平台的素材、文案、发布形式都不一样。以前一期视频全部发完，要花我一个小时左右。现在 Agent 写文案、插件去填、麦田盯着，我要做的基本只剩一件事：国内那四家，最后自己点一下发布。

所以它其实是一套东西：自动化发布，加上运营监控，加上流量监控。

如果你也在做内容，想做多平台分发，或者手里已经有好几个平台的账号，想把数据放在一起盯着看，希望我这套东西能帮上你一点。

省流版：所有功能、整个流程，已经全部开源了。懒得看的直接拿走：

  • 麦田 https://github.com/CzzzzzzJ/mdldm-maitian
  • 麦田发布助手（Chrome 插件）https://github.com/CzzzzzzJ/mdldm-maitian-publisher
  • 一行安装：bash -c “$(curl -fsSL https://raw.githubusercontent.com/CzzzzzzJ/mdldm-maitian/main/scripts/install.sh)”
    想知道它到底能干嘛，接着往下看。

中间是粉丝：七个平台加起来一共多少粉，今天、近 7 天、近 30 天各涨了多少。柱子是每天的净增，发视频的日子会标出来，哪一期带粉了，一眼就看得到。

右边这块我最喜欢，它直接用人话告诉我：这周哪个平台涨粉最多，这一期发布当天有没有带来额外涨粉，哪个平台互动率最高。不用我自己去算。

这一期到底行不行？

点进任何一期，能看到它在每个平台的状态、链接和播放走势。

这里最有用的是复盘。发布后第 1、3、7 天，麦田各给我推一次，而且是拿同一天比同一天。

为什么要这么比？新视频才发了一天，你拿它去跟老视频攒了好几天的播放比，那永远是输的。同一天对同一天，才看得出这一期到底行不行。我上一期发出去一天两万两千多播放，是上一期同一天的六倍，看到的时候还挺开心的。

哪个平台值得我花力气？

转化页，哪个渠道带来了多少注册、会员、收入，每一期从播放到注册、到会员、到收入，一层一层的漏斗。这一块为什么对我这么重要，下一节细说。

除了这三块，还有几个页面是日常用的：日历，看上周到未来两周排了哪些内容；流量，看每一期在每个平台的播放和互动；档案和系统，存文案、看登录状态。用到的时候点开就行，这里就不一一展开了。

二、为什么我要把知识站接进来

这部分我是拿我自己举例子。

现在大家的变现方式多种多样，我的链路其实很简单：把公域上的用户引到我的知识站，对我的内容感兴趣、想持续学的，来开 VIP。公域引流，私域转化，这就是我完整的商业链路。

所以我把知识站也接到了麦田后面。我最想看的就是，各个平台到底给知识站带来了多少人，最后多少人注册、多少人付费。哪个平台给我的价值最高，哪个平台的粉丝付费意愿就是不强，我得心里有数，才知道接下来往哪儿使劲。

给你们看一个我自己的真实数字。从小红书来注册的人，有 8.8% 最后成了会员。X 带来的注册其实更多，六百多个，但转成会员的只有 1%。

这个差距说实话有点扎心，但它直接决定了我以后每个平台花多少力气。

这一块我也是开放的。你有自己的中转站、独立站，或者个人产品、个人项目、个人 SaaS，都可以接进来，看看公域流量给你带来的转化到底是什么样子。怎么接，后面第八节说。

三、发布是怎么跑起来的

接下来讲一下发布是怎么完成的。

我本地的 Agent 负责想和写：剪完的片子丢给它，它看一遍，把各个平台的标题、正文、标签写好，连同成片和封面打包成一个发布工程。

麦田发布助手负责填。这是一个 Chrome 插件，挨个打开各平台的上传页，把视频、封面传上去，文案填好，定时设好。

麦田负责管：什么时候开跑、跑到哪一步、哪个平台出错，每一步都往飞书群里推一张卡片。同一条视频每个平台只传一次，已经到位的平台绝对不会再跑第二遍。

插件仓库：https://github.com/CzzzzzzJ/mdldm-maitian-publisher

四、国内平台的风险，我必须讲清楚

这一段大家一定要认真看。

国内平台对自动化发布管得是真的严，监管也重。所以我这套东西做的事情很有限，就是把你在本地整理好的内容，填到各个平台的发布页面，帮你把素材传上去。

也就是说，它只管上传素材。

所有内容的调整，包括最后点「发布」的那一下，全都要你自己手动来。

千万千万，不要为了图省事把它改成全自动。我这里最多就是给你一个快捷上传的办法，别的不碰。

在我这儿，X、YouTube 和我自己的知识站，麦田核对完定时会自己提交。B站、抖音、小红书、视频号这四家，它填好就停，状态就挂在「待你发布」，老老实实等我自己去点。

五、数据是怎么拿到的

分析页面这些数据怎么来的，我就不讲太细了。讲得太透，我怕平台针对，到时候大家都不好用。

简单说一句，它不是那种模拟点鼠标的 RPA。像小红书这种风控特别严的平台，我用的是最保守的办法，频率也压得很低。

真想细了解这一块的，可以来我的私域找我聊，或者来我的知识站，课程和每周直播里我会讲得更细一点。

六、它跑在什么上面

基础设施其实很简单。

一台常开的 Mac mini，里面开一个专用的 Chrome，各个平台都在这个浏览器里登录好。麦田本身不存任何密码。

成片放在 NAS 上，NAS 偶尔掉线，麦田会自己把它重新挂回来。通知走飞书群机器人，全是卡片，手机上看着也舒服。想在外面用手机看大屏，就开一个隧道，出门在外也能随时瞄一眼。

那没有常开的电脑，用云端行不行？其实也有办法，找一台带桌面的云服务器，一样能跑起来。但我自己不这么用：国内平台对登录环境很敏感，账号突然换了设备、换了 IP，很容易触发风控。所以登录平台、填发布页这部分，我建议还是放在你平时自己用的电脑和网络上。

七、开源了，怎么用起来

好，接下来就是大家最关心的部分。

开源的一共三块，配合着用：

  • 发布 skill，给 Claude Code 这类 Agent 用，负责看片、写文案、生成发布工程
  • 麦田发布助手，就是前面那个 Chrome 插件，负责在各平台里填。已经提交 Chrome 应用商店了，审核期间先从 GitHub 下载
  • 麦田本体，负责调度、监管、数据和复盘

安装我尽量做成了一行。打开终端，把这句贴进去就行。

bash -c “$(curl -fsSL https://raw.githubusercontent.com/CzzzzzzJ/mdldm-maitian/main/scripts/install.sh)”

它会把麦田和插件下载到你电脑上，把发布 skill 接进 Claude Code，然后打开一个安装向导。向导问你几个问题：插件放在哪、视频放在哪、飞书机器人的地址是什么。问完它帮你生成配置、装好开机自启，再把各个平台打开，你挨个登录一次就好。

只想先看看长什么样，不想接任何平台，也行。装好以后在麦田目录里跑一句 node src/demo.mjs，它会用一份假数据把整个麦田跑起来给你看。

上手我建议分三步走：先只看数据，半小时就能接好；用顺了再让它帮你分发；最后再接转化。

麦田 https://github.com/CzzzzzzJ/mdldm-maitian

麦田发布助手 https://github.com/CzzzzzzJ/mdldm-maitian-publisher

八、把你自己的项目接进来

前面说了，靠自媒体变现，除了接广告，还有一条路就是做自己的项目。课程、社群、小工具、付费服务，都算。

要做的事情其实不多。发视频的时候，链接里带上这一期的标记；你的项目那边，记下访客第一次是从哪条链接进来的；再给麦田提供两个只读接口。接好以后，转化页上就会出现每一期的漏斗。

整个项目对 Agent 也特别友好。代码结构很简单，接口格式都写在 README 里。你让 Claude Code 把仓库读一遍，告诉它你的项目长什么样，它基本就能帮你接好。拿来做二次开发，非常合适。

最后

欢迎大家来用麦田。

如果觉得有用，去 GitHub 给它点个 Star，这对一个刚开源的项目真的很重要，也是我继续往下改的动力。用的时候遇到问题，直接提 Issue，我是一边发视频一边在改它的。

也想听听你们的：你最想让麦田接哪个平台？或者你现在多平台运营最头疼的是哪一步？ 评论区告诉我，呼声高的我优先做。

我也建了一个群。对麦田感兴趣，或者想一起聊聊怎么做多平台运营的，欢迎进群找我。

我是麦当，带你用 AI 玩点实际的。

Grok Bot、Muse机器突围沙箱隔离：Zero Trust 隧道打通外网，附保姆级步骤

发表于2026-11-16|行业观察
|浏览量:

本文转载自 X 博主 @awe0_io（awe0） 的长文，原文链接，版权归原作者所有。

前言

大家都知道，开通premium之后就可以使用 grok bot，给的机器配置还是可以的。然而机器系统做了沙箱隔离，只能使用 bot 做一些定时、自动化任务，完全浪费了这台机器的资源。本着不浪费资源的初心，研究了一下如何突破沙箱隔离，最终做到了外网可访问自己部署的服务，下面把折腾心得分享给大家。

机器配置

我这台机器的配置如下：

  • CPU：8 核 Xeon
  • 内存：16GB
  • 硬盘：126GB
  • 系统：Debian 13 容器
  • 带宽：下行将近 2GB，上行 500M，应该是共享带宽
  • 区域：美国东部

准备工作

本次折腾需要用到的服务：

  1. cloudflare：隧道内网穿透
  2. digitalplat：免费域名

破界流程

第一步：准备域名

cloudflare 需要绑定一个域名：已有域名的，点击添加域名，然后设置域名的 DNS；没有域名的，去 digitalplat 注册免费域名，有效期 12 个月，之后免费续。

第二步：创建 cloudflare 隧道

1. 进入 Zero Trust

登录 cloudflare，点击左侧菜单的 Zero Trust。

2. 创建隧道

跳转到 Zero Trust 之后，点击左侧菜单：网络 → 连接器 → 右上角点击创建隧道。

3. 填写隧道名称并保存

创建隧道时选择第一个，然后输入隧道名称，保存。

4. 安装连接器

保存之后选择操作系统，复制指令，按照流程安装。

5. 建立连接

安装完成之后建立连接，底部的连接器会自动刷新出你的机器，点击下一步。

6. 设置子域名和服务

接下来设置子域名和服务；如果没有绑定域名，先完成域名设置，这一步暂时跳过。

7. 添加应用程序路由

完成后就可以在连接器中添加应用程序路由了，将自己的服务开放到公网，通过你的子域名访问。

8. Muse

Muse同理，只不过需要在bot中让他装cloudflare，然后将连接认证的bash发给他让他执行安装，就能建立连接了。

小技巧：在cloudflare增加ssh浏览器应用程序，可使用cloudflare进行认证登录直连muse机器的ssh。

cd /home/hatch/workspace 这个目录重置机器会保留数据，所以将所有的东西装的这个目录。

Muse机器配置（凑合用）

流程总结

整个流程总结如下：

  1. cloudflare 注册账号；
  2. 在 cloudflare 绑定自己的域名；
  3. 在 grok bot 机器部署 cloudflare；
  4. 部署完成后，将本地端口去 cloudflare 做外网域名映射；
  5. 享受～

如果没有域名，去 digitalplat 注册免费域名，有效期 1 年。

实测：游戏部署

这套方案也可以用来部署游戏。需要注意的是：cloudflare 绑定的域名不支持 tcp 协议，要用到 cloudflare 本地流量转发才能连接。

常见问题

Q1：grok bot 有的机器是国内的，有的是亚太的，这是为什么？

跟你的代理节点有关系，grok bot 会根据你的节点给你分配最近、速度最快的机器。所以开 bot 机器最好使用美国节点全局代理，要其他区域同理。

Q2：grok bot 会重置机器，怎么解决？

bot 是会重置机器的，而且你不活跃了就将机器休眠了。解决方法：所有的软件都安装到 cd /workspace/ 这个目录下——这个工作目录的数据，重置或者更新机器也会保留；休眠问题只能写定时任务，在 grok bot 发送信息活跃一下了。

注意⚠️

cloudflare 条款中不允许 CDN 分发视频或大文件（付费服务），搭建订阅节点服务可能会封禁域名报 403 异常。

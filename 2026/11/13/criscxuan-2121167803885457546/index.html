离谱，Karpathy 顺手搓了个 YouTube ，而我顺手给他搓了个中文插件。

发表于2026-11-13|行业观察
|浏览量:

本文转载自 X 博主 @criscxuan（cxuan） 的长文，原文链接，版权归原作者所有。

what ？？？

某社交平台知名大佬 Andrej Karpathy 发帖称，由于他受不了 youtube 的推荐算法。

所以花了两个小时直接用 Opus 5.5 手搓了一个复刻版 youtube 出来。。。

名字叫 HackerTube 。

为了做这个 HackerTube ，Karpathy 从 20 年来 HN 的 4300 万条评论中筛选出了 6454 个持续被推荐的视频。

也就是说这个 HackerTube 都是精选中的精选，它过滤了很多带有噪声的视频。

但同时也可以说，由于它是被持续推荐的原因，所以大部分视频都已经很老旧了。

比如我随手刷新一下，几乎都是 10 几年前的，最近两年的都很少。

而且这个 HackerTube ，它是无需登录就能看。

在无论什么平台都需要登录的情况下，有一个无需登录就能看精选视频的平台简直就是赛博活菩萨了。

没错说的就是你，卡帕奇。

不过这些都是英文，为了表达我对卡帕奇老哥的尊敬和支持，我用 Opus5.5 和 Fable 5.2 一起搓了个 HackerTube 的翻译插件

直接在线在线翻译，我用起来挺顺手的，给大家看下效果。

基本上分类的很全乎，比如点开计算机历史与文化，它是这样的。

卧槽这个太绝了啊，这太尼玛硬核了。简直是经典中的经典，突然明白了卡帕奇老哥做这个视频站的意义。

同样的也支持中文搜索，比如我搜索马斯克，出来的视频是这样的

不得不说 13 年前老马年轻的时候果然非常帅啊

emmm ，在搜索某个 Java 之父的词条，果然没搜到，看来卡帕奇老哥也得敲打一下了，竟然不知道 Java 之父。

不过这几个视频看起来很值得一看。

如果说文字对应的 Knowledge Base 叫知识库的话，那这个视频站的 Knowledge Base 简直可以称之为视频知识库了 ：）

所以后面要不要把所有视频的内容都撸出来整一个知识库给大家订阅下呢 ：）

emmm ，该说点正经事儿了，这个视频字幕翻译插件我直接放到了 npm 上，一行命令你就能安装，丝滑体验一下 HackerTube 中文插件的效果。

npx hackertube-zh

不过这个插件还没上 Chrome 应用商店 ，目前安装插件之后，

需要按照下面三个步骤来配置一下

  1. 地址栏打开 chrome://extensions（安装器已把它复制到剪贴板，直接粘贴）

  2. 右上角打开「开发者模式」

  3. 点「加载已解压的扩展程序」，选择 hackertube-zh 的安装目录。

最后本来想给大家推荐几个硬核频道来着

但是我翻了一圈 。。。 这怎么推荐，每一个都很硬，看完纯纯学到东西的那种。

（太坏了，今天怎么又让我学到东西了）

比如这个 PS5 之路。

文章的最后，emm 遇事不决，我们还是量子力学把

OK ，今天文章就是这样，希望对大家有帮助。

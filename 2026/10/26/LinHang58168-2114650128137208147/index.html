Devin Desktop 从入门到进阶：界面拆解、Fusion 模型搭配与隐藏技巧

发表于2026-10-26|行业观察
|浏览量:

本文转载自 X 博主 @LinHang58168（OnChain航） 的长文，原文链接，版权归原作者所有。

说明：本文基于 Devin v3.10.67整理，不同版本和账号类型下入口位置可能有差异。

最近被 X 上认识的波兰朋友送了一张 $200 的devin订阅，决定把Devin Desktop深度用起来。Devin Desktop很多很强大的功能，但是对于刚下载或者经常用codex的用户可能比较懵逼。希望通过这篇文章，能帮助你快速了解Devin的功能。

Devin Desktop 的界面入口多，有时候感觉像codex有时候又感觉像VScode编辑器。这篇文章希望从安装、到界面认识、到常用功能、到进阶使用。

PS: 个别界面元素会随版本变化，最近Devin还在新的客户端Devin Next。

01｜安装

先去官方文档的快速开始页下载稳定版，Mac、Windows、Linux 都有对应安装包，按各平台常规方式安装即可，这里不逐一列安装命令。

第一次启动会让你先选主题（背景界面是黑色还是白色），然后留意 Import settings 这个可展开区域，展开后能把 VS Code 或 Vim 的设置和键位导入进来，可以降低VS Code/Vim 用户的迁移成本。如果没有VS Code/Vim 配置可以不用理会。

我电脑上已经装了很久了，找了台mac重新安装了下，给大家截图看下

PS: Install devin-desktop 是安装一个命令行启动Devin Deskstop, 不是Devin的命令行cli，命令行cli需要额外安装。

接着是登录。默认走浏览器跳转登录 Devin 账号。如果已有账号，直接登录即可。如果没有账号，需要先注册并购买订阅，没有订阅套餐，devin能用的模型和功能很少。

装完还有两件可选的事。一是文档里提到的 devin-desktop 终端命令，只在需要命令行启动时才装，纯 GUI 使用不强求。

另外有个地方可以注意下，Devin Desktop 是基于 VS Code 开发的，VSCode插件几乎都是兼容Devin的，对常年使用VSCode的人，基本是无缝迁移。

02｜认识界面

打开应用先看到开始页。这是一个让人熟悉的codex界面布局，但是比codex多了一个 IDE View（Windows）

序号1区域：Agents View 和IDE View切换，Agents适合大众玩家，IDE View适合程序员

序号2区域：保存最近和AI沟通的会话（Session）

序号3区域：打开设置，用于设置AI权限、字体、主题、键位、套餐使用量等等

序号4区域：输入区域，用于和AI沟通需求或者想法

序号5区域：模型切换，用于切换不同的模型，Devin支持主流的Cluade、ChatGPT、Gemini、Grok、Muse、DeepSeek、GLM、SWE大模型，Devin强大的Fusion模型也在这里设置，后文来讲

序号6区域：Local/Cloud, Local标识基于本地文件开发，Cloud则可以连接Devin虚拟机开发项目（比如Windows可以通过Cloud构建Mac应用）

03｜模型和模式

在输入框下方点开模型下拉菜单，或者在聊天输入框里输入 /model，就能切换当前会话使用的模型。

除了直接选某一个固定模型（如 SWE-2、Claude、GPT、Gemini 等），列表里还有两种常用的组合方式：Adaptive 和 Fusion。很多人装好后分不清这两个名字，其实它们解决的是两种不同的省心需求。

Adaptive：按请求自动路由

它的逻辑很简单：你每发一条消息，Devin 先判断难度，简单问题交给速度快、成本低的模型，复杂问题再交给能力更强的模型。另外，保持在同一场对话里连续交互更容易命中提示缓存，输入成本也会更低；把需求写具体一点，路由器更容易一次选对模型。

Fusion：主导模型 + 辅助模型搭配

Fusion模式是一个强大的模式，推荐大家用起来。选中 Fusion 模式后，界面上面对的还是同一个 Devin，但后台会由两个模型配合干活：

  • 主导模型（Lead）：用前沿模型负责规划、架构判断、排查难点和结果审查。
  • 辅助模型：用性价比更高的模型按计划写代码、跑构建和测试、做机械性的实现与验证。

因为大量常规编码和验证跑在辅助模型上，整体花费会比全程单跑前沿模型低。点进 Fusion 系列后，你可以配置四个选项：

  1. Lead：选哪个前沿模型主导会话。
  2. Effort：主导模型在回复前投入多少推理算力。
  3. 辅助模型：选哪个高性价比模型干具体活，每个主导模型都会给出推荐搭配。
  4. 快速模式：可用时切成同系模型的更快版本，智能水平不变、速度更快，但费率更高。

第一次用不用自己乱配，我直接直接用 Cluade Opus 5.5 + SWE-2 这个搭配开始，这一组针对主导模型给多少细节、把哪些探索工作交给辅助模型做过专门调优。

04｜权限和工作模式

刚开始使用Devin的时候，你会发现Devin几乎没执行一个问题，都要找你授权，我提供给你一句提示词，用于解决该问题

工作模式：Normal、Plan 和 Ask

Devin Local 有三种工作模式，用输入框附近的模式控件切换，或者在聊天输入框里输入 / 查看当前支持的切换命令（如 /normal、/plan、/ask，也可以用 Alt+P 切换 Plan 模式）：

Plan 模式生成的方案会保存在 ~/.devin/plans/plan-.md，你可以直接打开修改，或者留给新会话继续用。

05 | IDE View

IDE View如果是程序员应该比较熟悉了，它的左侧区域是文件区用于查看文件目录树，中间是代码区用于文件编辑区用于编辑文件或者代码，右侧是AI沟通区用于用户和AI沟通需求，这个模式更适合程序员来使用，方便查看AI写的代码

最左侧还提供了丰富的功能，像Git生成commit log并提交，Codemaps、DeepWiki

另外还是VSCode Remote SSH功能，完美复刻VSCode

05｜Devin Cloud

这是Devin的一个强大的功能，但是很少看到有人讨论

  • 你可以通过Devin Cloud模式直接在Windows上指定一个Github仓库构建Mac/iPhone应用

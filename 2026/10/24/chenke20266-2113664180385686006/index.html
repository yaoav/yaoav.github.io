如何用 Claude 交易 PUMPFUN 和 Solana 打新：7 个提示词、4 张表、1 套系统

发表于2026-10-24|交易策略
|浏览量:

本文转载自 X 博主 @chenke20266（上车的乘客） 的长文，原文链接，版权归原作者所有。

98% 的 pumpfun 代币从来没离开过联合曲线（bonding curve）。

大多数交易者亏在那里，原因只有一个：他们只有 4 秒做决定，一个人，K 线还在耳边尖叫。

Claude 治不好你的进场点，但它治得了那 4 秒。

它会读你跳过没看的持仓分布，会查你忘掉的 dev 钱包，会把你凌晨两点破的那条规矩写下来，周日再摆到你面前。

这是完整的搭建方法：终端、工作流、提示词、表格。全部抄走。

第一部分 为什么大多数终端玩家一直在流血

标准配置长这样：

1 个终端。6 个标签页。3 个 Telegram 群。0 条写下来的规则。

一个币 11 分钟拉了 +300%，你在顶部买入。90 秒内砸掉 80%。你跟自己说：运气不好。

不是运气。是漏了 3 项检查：

速度不是你的问题，漏检才是。

第二部分 工具栈

你需要 4 层。它们都不替 Claude 下单。Claude 永远碰不到你的私钥。

保住账户的那条规矩：

Claude 负责分析，你负责点鼠标。

永远不要把助记词或私钥贴进任何 AI。一次都不行。”就试一下”也不行。

第三部分 搭一个”分析师” Project

新建一个 Claude Project，取名 TRADING DESK，把下面这段贴进自定义指令。这是你的”第二大脑”，你的规则已经烤进去了。

你是我的 Solana meme 币 / pump.fun 打新交易分析师。
你永远不建议我买入。你只负责打分、标风险、执行我的规则。

我的规则（强制生效，我违反了就直接点出来）：

  • 单笔最多用账户的 2%。最多同时持有 5 个仓位。
  • 前 10 大持仓（不含联合曲线 / LP）合计超过 25%，不进。
  • dev 持仓超过 5%，或在前 10 分钟内卖过，不进。
  • 代币上线超过 6 小时且没创新高，不进。
  • 涨到 2 倍卖出 50%。亏到 -35% 止损。无例外。
  • 我本地时间凌晨 1 点之后不交易。

我每发来一个代币，都按这个格式输出：

  1. 评分：0-10
  2. 红旗：逐条列，最危险的放最前
  3. 绿旗：逐条列
  4. 规则检查：上面每条规则 通过 / 不通过
  5. 结论：放弃 / 观察 / 有效机会（永远不要写”买入”）
    整段控制在 150 字以内。不许用煽动词。

往 Project 里上传 3 个文件：

——你的规则（PDF） ——你最近 50 笔交易（CSV） ——一份你已知的跑路盘 / 狙击钱包名单

这样每次开新对话，都从”你的记忆已加载”开始。

第四部分 60 秒代币尸检

你在 Axiom 上看到一个刚开的盘。点进去之前，先跑这个。

用 Chrome 里的 Claude 打开代币页面，发：

读这个代币页面，提取：市值、联合曲线进度 %、持有人数、前 10 大持仓占比、
dev 钱包占比、dev 历史卖出记录、首个区块里的捆绑买入、5 分钟和 1 小时成交量、
买卖笔数比、社交账号（X、TG、官网）及其注册时长。
然后按 Project 指令里的规则，把全部规则检查跑一遍。

没有浏览器插件？把合约地址 + 持仓标签页的截图贴进去，输出一样。

一个真实的回答长这样：

评分：3/10
红旗：

  • 7 个钱包在 block 0 用完全相同的 SOL 金额买入（捆绑）
  • 前 10 大持仓 38%（规则上限 25%）→ 不通过
  • X 账号 2 天前创建，14 个粉丝
    绿旗：
  • 曲线 71%，买盘稳定
  • dev 持仓 2.1%，没有卖出
    结论：放弃

38% 的集中度。block 0 里躺着一笔捆绑买入。你离买进去只差 4 秒。

第五部分 用 Claude 读联合曲线

Pump.fun 的代币在毕业（graduate）进 PumpSwap 之前，一直活在曲线上。每个阶段的玩法不一样。

毕业区的提示词：

这个代币现在处在联合曲线的 [X]%。
列出所有持仓超过 2% 的钱包。每个给出：首次买入时间、平均成本、
是否已经卖出过、是否在我已知的跑路名单里。
然后告诉我：如果前 5 大在毕业时全部卖出，按当前流动性，
现实的跌幅是多少 %？把数学过程写出来。

你不会在交易中途去算的那点数学，Claude 帮你算。

第六部分 叙事扫描

meme 币交易的是故事，不是技术。最好的进场点在叙事起来之后 20-40 分钟，不是 2 小时以后。

每天早上跑这个：

扫描过去 12 小时的 X 和新闻，找出 5 个今天可能催生 meme 币的叙事：
爆火的动物、AI 发布、名人事件、政治事件、梗图格式。
每个给出：核心梗、可能的 ticker 名（3-5 个）、早期程度（1-10）、什么会杀死它。
按”早 + 强”排序。

然后在终端里给这些 ticker 设提醒。一旦有匹配的新盘出现，直接进第四部分的尸检。

第七部分 用 Claude Code 造你自己的扫描器

从这里开始，它不再是聊天，而是一台机器。

在一个空文件夹里打开 Claude Code，发：

写一个 Python 脚本：

  1. 通过公开数据接口每 15 秒轮询 pump.fun 的新代币。
  2. 每个代币用 Helius RPC 拉持仓分布（key 从 .env 读，绝不硬编码）。
  3. 过滤：前 10 大 < 25%、dev < 5%、block 0 买家不超过 3 个、曲线进度 15-80%。
  4. 通过的代币推送到我的 Telegram 机器人，附：合约地址、市值、曲线 %、
    前 10 占比、代币页面链接。
  5. 每个代币（通过或未通过，都带原因）写进 tokens.csv。
    只读。不接钱包、不签名、不下单。
    先给过滤逻辑写测试。

40-60 分钟后，你就有了一个过滤器：它读每一个新盘，只对通过你规则的那 2-5% 给你推送。

点还是得你点。但你只看活下来的那些。

第八部分 一份真能改变你的交易日志

每笔交易记进一个 CSV：时间、代币、进场、出场、仓位、盈亏、进场理由、出场理由、有没有破规（是/否）。

每周日，把它上传到 Project：

这是我本周的交易。

  1. 按交易时段、曲线阶段、叙事新鲜度，分别给出胜率和平均 R。
  2. 我破得最多的是哪条规则？折成 SOL 让我损失了多少？
  3. 我最差的 3 笔交易，共同点是什么？
  4. 加一条规则，删一条规则。用数字解释。
    直接说，别安慰我。

第一次跑它的时候会疼。它本来就该疼。

大多数交易者会发现同一件事：80% 的亏损来自两个行为——夜里交易，和报复性进场。

不承诺 100 倍。这是纸面上”纪律”长什么样。

〔图〕

有些月份就是红的。日志会告诉你：那是市场的问题，还是你的问题。

第十部分 之前 / 之后

之前： 6 个标签页。凭感觉。买在顶部。怪 dev。

之后： 1 个终端。1 个 Project。60 秒尸检。跳过捆绑盘。记下原因。

之前： “下次我会记住这条规则的。”

之后： 规则活在文件里。Claude 每笔交易都读它。

彩蛋

完整的提示词包，一块拿走，存成一条笔记。

抽检： 读这个代币，跑完我的全部规则检查，只给结论。
曲线： 列出所有 >2% 的钱包，模拟毕业砸盘，把数学写出来。
叙事： 过去 12 小时的 5 个叙事，按”早 + 强”排序。
离场： 我浮盈 [X]%，持仓情况是 [数据]。请论证现在就该卖。
上头： 我刚亏了 [X] SOL。接下来一小时该不该交易？用我的日志判断。
复盘： 周度 CSV。最差的规则、折成 SOL 的代价、加 1 条、砍 1 条。
扫描器：只读版 pump.fun 过滤器，Helius RPC，Telegram 推送，CSV 日志。

光是 TILT 这一条提示词救回来的账户，就比任何指标都多。

不是财务建议。meme 币一分钟就能归零，而且大多数确实如此。

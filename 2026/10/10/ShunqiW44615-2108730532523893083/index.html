靠AI帮大学生写代码，1个月净赚12万元，我是怎么做到的？

发表于2026-10-10|行业观察
|浏览量:

本文转载自 X 博主 @ShunqiW44615（晚山秋） 的长文，原文链接，版权归原作者所有。

作为一个读不懂论文的外行人，这两周来，我一直在用AI帮助研究生复现论文代码，目前为止，我的1个闲鱼号+2个小红书号，三个号加起来一共34单，半个月到手 60,240 元。**而这34单里，用户指定的论文，我能真正从头到尾读懂的，几乎没有。**且听我揭秘事实的真相。

（ps：本文非AI撰写，均为一字一句手敲。）

先看收入构成。闲鱼是新注册的号，从 0 开始做，半个月赚了 1w3 ；大头在小红书，一个新号（权重低，要冷启动热号），一个日常号改造（可以直接批量发），两个号一共赚了4w7。

1. 平台用户：需求信息差，知道谁愿意花钱

找上门的客户大致分为两类：

1）导师布置作业要求复现论文的研究生。这种客户预算比较低，客单价扯皮后勉强过四位数。

2）研究生手上已经有一篇对标论文，想在它的方法上改一改，换一个模块、加一个约束、换一组数据，做出一点改进，拿去写自己的新论文。这种客户预算比较高，但凡你有点销售能力话术，客单价无上限。

这些客户为什么愿意花钱？我跟他们聊下来，发现大概 90% 的人只会用 DeepSeek 这类聊天工具，连 Codex、Claude Code 这种能直接读代码、改代码、跑代码的智能体都没用过。剩下 10% 的人倒是用过 ChatGPT，但提示词功底太弱，对 plan 模式、skill、工作流这些 agent 用法完全不了解，把报错贴进去来回问了几十轮，还是聊不出结果。

这就是客户层面的信息差。大量学生卡在代码上，一卡就是一两周，可他们不知道这件事用对了AI工具几个小时就能解决。

2. 交付过程：AI工具的使用，技术层面0门槛

刚开始我也是一单一单跟 AI 聊，每次都要把论文从头讲一遍，一天最多做两单。后来我把这个过程拆开，写成了几个固定的 skill，相当于给 AI 定好了一套工作流程。

这套东西搭好之后，我在中间做的事情其实很少：看一眼实现清单有没有明显漏项，看一眼最终结果和论文差多少，然后把东西交给客户。论文里的公式怎么推导、为什么这么设计，我不需要懂。我不懂机器学习算法，也不懂供应链管理理论，照样能交付这两个方向的单子。

这 34单里，计算机方向的只有7单（可能计算机专业的人确实更懂ai），剩下的来自物流、电力系统、工业工程、交通这些方向。做路径规划的、做电力调度的、做车间排产的、做选址优化的，只要论文最后落在 Python 或者 Matlab 代码上，流程就是一样的。很多这类专业的学生代码基础比计算机专业弱得多，卡在代码上的比例反而更高，愿意付钱的意愿也更强。

3. 闲鱼/小红书运营获客：话术技巧+知识干货都要有

获客这块，推特上很多人分享闲鱼和自媒体运营技巧挺久了。核心就几条：标题一定要吸引人；多模仿别人的高流量帖子，怎么好用怎么来；只模仿那些真正拿到结果的帖子。

我自己再补充一点：这种技术性很强的服务，帖子里一定要多放干货。学术干货可以直接问 AI，也可以参考相关学术公众号的内容。客户看到你讲得专业，才敢把论文和钱交给你。

闲鱼这个号是从 0 做起来的。我挂了几个商品，标题里直接堆学生会搜的关键词，比如深度学习、路径优化、电力调度、车间调度、Matlab、Python，主图用的是复现结果的对比截图。前三天几乎没人问，第四天开始每天有 5 到 10 个咨询。半个月三个商品累计 3,200 多次浏览、282 个“想要”，最后成交 14 单。闲鱼的客户爱砍价，单价普遍不高，适合走量、攒好评。

小红书笔记当天就爆了，0粉发帖，第一篇帖子直接就干到了500个收藏，20+私信，这个技巧后面有时间分享。

4. 最后总结：普通人能不能做

我自己不是这些专业出身的，这半个月接的大部分论文，我连摘要都没认真读完，即使借助ai认真读也不一定读得懂。

这件事的门槛在于你愿不愿意花几天时间，把复现的流程一步步写成 skill，再在前几单里不停地修它。前几单会很慢，因为 skill 总有考虑不到的地方，每修一次，下一单就快一点。到第二周，大部分单子我已经只需要做开头和结尾的检查了。

如果这篇文章反响不错，我后面再单独写两篇：一篇讲获客的具体做法，一篇讲这套 skill 工作流是怎么一步步搭起来的。
